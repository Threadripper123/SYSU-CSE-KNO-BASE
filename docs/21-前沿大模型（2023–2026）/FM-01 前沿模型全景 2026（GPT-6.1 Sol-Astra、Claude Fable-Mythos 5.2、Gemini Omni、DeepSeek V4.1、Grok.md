# FM-01 前沿模型全景 2026（GPT-6.1 Sol/Astra、Claude Fable/Mythos 5.2、Gemini Omni、DeepSeek V4.1、Grok、Qwen、Llama）

**一句话结论**：2026 年的前沿模型竞争已经不是「谁家模型最强」，而是「谁家的家族分层、努力度档位和速度模式组合起来最省钱」。OpenAI 把 GPT-6 拆成 Astra / Sol / Luna 三档并按 **1 : 1/5 : 1/100** 的价格阶梯定价，Anthropic 用「同一个底层模型 + 两套护栏」的双名策略（Fable / Mythos）加 5.5 家族四档，Google 同时维护 Gemini 4 与 Gemini Omni 两条产品线，DeepSeek 用 1M 上下文加峰谷价差从下方切市场。

## 〇、三年三段：这份全景的时间坐标

**2023-11 至 2024 年是「按代跳跃」**：选型只看单个模型版本号，同一厂商一年推两三代，价格以每百万 token 十几美元为常态，长上下文和工具调用是加分项而不是默认能力。

**2025 年是「思考长度参数化」**：推理模型把思考长度变成一等公民，开源推理模型把输出价压到分位区间，闭源侧开始出现 first-class 的 effort 档位，评测从「单分数」转向「分数 + token 预算」。

**2026 年是「家族化 + 档位化」**：同一代际内出现 1 : 1/5 : 1/100 的价格梯度，模型名不再等于能力等级，护栏、速度模式、努力度都成了独立变量。评测口径也随之变化——2025 年之前的榜单大多是单次、无工具、零样本；2026 年主流发布页给的是「努力度 × 成本」曲线，Anthropic 5.2 页面把每个基准都画成 accuracy 对 cost 的双对数图，并注明 highest-available effort。这意味着跨厂家的分数即使数字相同，背后的 token 预算也可能差几倍到几十倍，横比必须先把 effort 固定下来。

## 二、四家的产品结构差异

### OpenAI：一个型号三段价

GPT-6 不是单一模型，而是**同一代际下的三档能力**，官方在 10 月 2 日的模型指南里直接标价（每百万 token）：Astra 输入 $10.00 / 输出 $50.00 / 缓存输入 $1.00；6.1 Sol 输入 $2.00 / 输出 $10.00 / 缓存输入 $0.10；Luna 输入 $0.10 / 输出 $0.50 / 缓存输入 $0.01。官方对 Sol 的定位原话是 near-Astra intelligence for a fifth of the price——「五分之一的价钱买到接近 Astra 的智能」。

命名上容易踩坑的两点：**（1）6.1 是小版本迭代而非新一代**，GPT-6.1 Sol / GPT-6.1 Terra 是在 Sol、Terra 线上加 0.1，Astra 仍是能力顶；**（2）Terra 在 GPT-6 世代没有同步出现**，6.1 Terra（10-26）官方只强调大规模 computer use，与 5.6 时代「Sol/Terra/Luna 三兄弟同发」的节奏不同。此外，GPT-5.6 引入的 `ultra` 档是「多 agent 并行编排」而不是更长思考，官方描述为 coordinating multiple agents across parallel workstreams。

### Anthropic：同一个模型，两个名字

Anthropic 2026 年最重要的结构变化是 **Fable 与 Mythos 是同一个底层模型**，差别在护栏而不是能力。官方原文：Fable 带强网络与生物安全护栏，因此可以对所有用户开放；Mythos 需要申请 Life Sciences 或 Cyber Verification Program 才能用。这解释了一个常见误解——选 Fable 不是「用了个弱一点的模型」，而是「用同一个模型的安全封装版」。

5.5 家族是三档阶梯：Opus 5.5（09-22，$4 / $20，缓存读取 $0.20，比 Opus 5 低 20%，典型负载成本低 40%，输出快 30% 以上）、Sonnet 5.5（09-28，比 Sonnet 5 快 30% 以上、多数工作便宜至多 30%）、Haiku 5.5（10-07，官方称比 Haiku 4.5 便宜约 75%）。官方给的使用建议是：日常编码与知识工作从 Opus 5.5 起步，向上升级到 Fable/Mythos，向下退到 Sonnet/Haiku，Fable 5.2 可以当 Advisor（被小模型咨询）或 Orchestrator（把简单任务分派给更小的模型）。

Fable 5 发布时还有一段值得记住的操作：护栏触发的话题会被路由给 Claude Opus 4.8 回答。也就是说「你请求的模型」和「实际回答的模型」在产品层面可以不相等，这在做可复现评测时是个硬坑。

### Google：Gemini 4 与 Gemini Omni 双线

DeepMind 官方模型页当前把 **Gemini 4** 放在旗舰位，给出 Gemini App、Google AI Studio、Google Antigravity 三个入口；另一条线是 **Gemini Omni**，官方一句话定位是 Create anything from any input – starting with video（任意输入到任意输出，先从视频开始），入口是 Gemini 与 Google Flow。两者不是「新旧关系」而是分工：Gemini 4 是通用旗舰，Omni 偏生成与多模态创作。

需要提示的是，Anthropic 在 5.2 的对照基准表里把 Google 当前模型写作 **Gemini 4 Carbon**。这是竞品页面上的第三方标注，`Carbon` 后缀在 Google 一手页上本轮没找到对应表述，引用时应当保留这个不确定性。

### DeepSeek 与其他中国厂商

DeepSeek 的 API 只有两个模型名：`deepseek-flash`（实际由 DeepSeek-V4.1-Flash-1017 提供服务）与 `deepseek-v4-pro`（DeepSeek-V4-Pro-0813）。两者都是 1M 上下文、最大输出 384K、thinking 模式为默认，Flash 支持视觉、Pro 不支持。

Qwen 在本轮只能从 arXiv 侧确认 Qwen3.5 家族存在（0.8B / 4B / 27B 变体与 Qwen3.5-Omni 技术报告 arXiv:2604.15804），官方 qwen.ai 博客为纯 JS 渲染，没有取到一手发布页。**Grok（xAI）与 Llama（Meta）在本机网络下完全不可达**，x.ai 与 llama.com 均未取得任何 2026 代际的一手数据，本稿不对这两条线做任何具体断言。

## 四、算一笔账：一条 33K token 的请求要多少钱

按「输入 30,000 token 全部未命中缓存 + 输出 3,000 token」估算（不含思考 token 与多轮重试，单位美元）：

| 模型 | 输入成本 | 输出成本 | 合计 | 相对最便宜档 |
| --- | --- | --- | --- | --- |
| GPT-6 Astra | 0.300 | 0.150 | 0.450 | 71× |
| Claude Fable 5.2 | 0.240 | 0.120 | 0.360 | 57× |
| Claude Opus 5.5 | 0.120 | 0.060 | 0.180 | 29× |
| GPT-6.1 Sol | 0.060 | 0.030 | 0.090 | 14× |
| DeepSeek-V4-Pro（谷） | 0.0198 | 0.0059 | 0.026 | 4.1× |
| DeepSeek-V4.1-Flash（峰） | 0.0090 | 0.0036 | 0.0126 | 2× |
| GPT-6 Luna | 0.0030 | 0.0015 | 0.0045 | 1× |

结论很直白：**头部模型与最便宜档之间差两个数量级**（0.45 对 0.0045，约 100 倍）。把 Astra 当作默认模型跑批量任务，成本会是 Luna 的百倍级。真正的工程问题不是「哪个模型最强」，而是「这条请求值不值得用 100 倍单价」。缓存命中能把输入侧再压一个数量级（Astra $1.00 对 $10.00，DeepSeek $0.022 对 $0.66），所以稳定前缀的整理比换模型更划算。

## 五、实际影响

**1. 选型从一维变四维。** 过去选「哪个模型强」，现在要同时定：家族（Astra/Sol/Luna、Fable/Mythos、Opus/Sonnet/Haiku）、版本（6 还是 6.1）、努力度、速度模式。定错任何一个维度的代价都可能超过换厂商。

**2. 价格阶梯比能力阶梯陡得多。** Astra 到 Sol 是 5 倍价差，Sol 到 Luna 又是 20 倍，而 Sol 的定位是「接近 Astra」。绝大多数生产流量应该落在 Sol/Luna 一档，把 Astra 留给真正的长尾难题和困难调试。

**3. 缓存价才是真杠杆。** 把稳定指令、参考材料放在 prompt 前部、把变化的任务细节放后面，比换模型更能省钱；OpenAI 的缓存输入最高可比未缓存便宜 95%（官方模型指南原文）。

**4. 安全策略会侵蚀可复现性。** Fable 5 时代「护栏话题降级到 Opus 4.8」是产品设计，不是 bug；做基准复现时必须记录实际回答模型，否则同一 prompt 换时间就可能换模型。

**5. 开源侧已经把差距写成文字。** Kimi K3 的技术报告直接承认「整体仍落后 Claude Fable 5 与 GPT-5.6 Sol，但稳定超过评测中的其他开源与闭源模型」（arXiv:2607.24653）。2026 年的开源叙述不再是「追平」，而是「稳定第二梯队 + 可自托管」。

## 六、常见坑与局限

- **把 6.1 当新一代**：GPT-6.1 Sol 是 Sol 线的迭代，能力顶仍是 Astra，两者价格差 5 倍。
- **把 Fable 当弱模型**：Fable 与 Mythos 是同一底层模型，差的是护栏与准入，不是权重。
- **把厂商表当第三方评测**：本文表 2 全部来自 Anthropic 发布页；GPT-5.6 的 Agents’ Last Exam 53.6（比 Fable 5 自适应推理高 13.1）同样是 OpenAI 自报。
- **忽略峰谷价**：DeepSeek 峰时（UTC 01:00–04:00、06:00–10:00，周一至周五，中国法定节假日除外）价格是谷时的两倍。
- **把 API 模型名当版本号**：`deepseek-flash` 背后是 DeepSeek-V4.1-Flash-1017，模型名不变而底层会换；旧名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍被接受，但请求会落到新模型并按 Flash 价计费。
- **本稿的结构性局限**：Google 侧只有模型命名的一手证据，没有发布日期、定价、上下文窗口；Grok 与 Llama 完全缺一手数据。这两块不能用推测补齐。
