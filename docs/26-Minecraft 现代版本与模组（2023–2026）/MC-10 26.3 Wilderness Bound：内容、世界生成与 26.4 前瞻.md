# 26.3 Wilderness Bound：内容、世界生成与 26.4 前瞻

> 资料截至 2026-11-15；覆盖 2023-11 至 2026-11，重点 2024–2026。

## 一句话结论

26.3「Wilderness Bound」是 2026 年"最像传统大更新"的一个 drop：新生物群系（斑驳森林）、新木材（白杨）、新结构（废弃营地）、一整套建筑方块（羊毛与混凝土的楼梯/台阶、坐垫、草垫床），外加 `/compute`、`/posteffect` 两个命令与 OIT 透明算法。它把 26.1 铺好的基建真正用起来，也让 26.4 的"冰洞穴"有了可复用的技术底座。

## 斑驳森林：秋天的白杨林

斑驳森林（Dappled forest）是秋季主题的森林群系，生成在寒冷群系附近。它的树种是**白杨**（poplar），一棵白杨在生成时随机取红、橙、黄三种叶色之一，每种叶色都有自己的落叶粒子；打掉叶子掉白杨树苗，种下去又会在三色中随机长成一种。所以"同一片林子颜色不齐"是设计，不是渲染错误。

林子里还有三样新东西：

- **红灌木**（Red shrub）：类似灌木的植物，成小片分布，用骨粉会尝试在相邻方块再长一株，可堆肥。
- **层孔菌**（Shelf mushroom）：长在白杨与倒木上，大小两态，小的可用骨粉催大，大的打掉掉 2 个。踩上去会弹（类似床），可以做蘑菇煲/迷之炖菜/兔肉煲，可堆肥，流浪商人有售。
- **倒木**（fallen tree）：白杨倒木的生成频率高于其他树种的倒木，且倒木上长层孔菌。

刷怪表按寒冷变体走：羊、鸡、牛、猪、兔、狐。这一点对整合包有实际意义——如果你的刷怪塔按"森林=温带变体"写死，在斑驳森林会拿到寒冷贴图的生物。

## 建筑与生活方块：这次更新真正的"手感"

26.3 新增的建筑方块看起来零碎，但组合起来是一整套"室内装修包"：

| 方块 | 关键属性 | 备注 |
| --- | --- | --- |
| 羊毛楼梯/台阶 | 16 色，可用羊毛合成，能吸音 | 只保留羊毛的吸音属性，不能当羊毛用（不能做床/地毯） |
| 混凝土楼梯/台阶 | 16 色，可由混凝土合成或用切石机切 | 补齐了混凝土一直缺的形状 |
| 坐垫（Cushion） | 16 色，可坐，无碰撞，可堆叠 16 | 用对应颜色羊毛台阶合成；只能放在平面上，支撑方块被拆就掉落；不会被活塞推动；除坐垫外可与其他物体重叠 |
| 草垫床（Straw bed） | 一次性，用后销毁；不重置重生点 | 3 个干草块合成 4 个；可堆叠 16；在下界/末地使用会直接销毁且不掉落；村民不会用 |
| 白杨船/带箱白杨船 | 白杨木板合成 | — |

草垫床的定位很明确：它是"野外过夜工具"，不是"重生点"。这条设计直接改变了探险流的节奏——你可以带一叠草垫床出门，睡完就走，不必担心把重生点绑在荒郊。代价是它一次性消耗，且在下界/末地使用会白给。

## 废弃营地与地图体系

**废弃营地**（Abandoned camp）生成在 18 个群系里：草甸、樱花林、森林、白桦林、原始白桦林、花林、风袭森林、斑驳森林、针叶林、雪林、原始云杉针叶林、原始松树针叶林、稀疏丛林、竹林、沼泽、热带草原、疏林恶地、苍白花园。每个群系有自己的变体：不同颜色的羊毛楼梯、草垫床与坐垫的摆法，或者带树叶、蜘蛛网、一棵树、一片农田。

箱子分两档：**普通箱**（铜制武器与盔甲、桶、指南针、地图、火药）与**秘密箱**（铁制武器与盔甲、钻石、金、药水）。木桶里是杂物，值得注意的是有几率出蜘蛛网。

地图体系是 26.3 的另一条暗线：

- 新增**废弃营地地图**，指向竹林、樱花林、白桦林、斑驳森林、花林、苍白花园、沼泽、风袭森林的废弃营地，出现在营地的"普通箱"战利品里。
- 新增**远古城市、废弃矿井、沙漠神殿、暖水海洋废墟**的探险家地图，出现在"秘密箱"里，与丛林神庙、沼泽小屋、试炼密室的地图同级。
- 同时把旧地图**改名**：Jungle Explorer Map → Jungle Pyramid Map、Ocean Explorer Map → Ocean Monument Map、Swamp Explorer Map → Swamp Hut Map、Trial Explorer Map → Buried Trial Chambers Map、Woodland Explorer Map → Woodland Mansion Map，并重画了所有探险家地图的物品图标。

改名看着无害，但对数据包与命令是硬变更：任何用旧物品 ID 写商店、任务奖励或 `/give` 的地方都要跟着改。

## 命令与数据包：/compute 与 /posteffect

**`/compute`** 把"数值提供器（number provider）"从数据包内部拉到了命令层，可以在三种上下文里求值：

- `/compute default integer <int_provider>`：只有位置与 `this` 实体可用的通用上下文；
- `/compute block <pos> integer <int_provider>`：带上该位置方块状态与坐标的上下文；
- `/compute entity <selector> integer <int_provider>`：带 `target_entity` 的上下文；
- 浮点模式 `/compute <target> float <float_provider> [<scale>]`，结果乘 `scale` 后向下取整。

还有一个容易踩的点：整数模式在中间步骤就截断，所以即使 `scale` 为 `1.0`，结果也可能与浮点模式不同；求值失败（例如除零）会让整条命令失败。

**`/posteffect`** 把后处理着色器变成可按玩家施加的效果：`add`、`remove`、`clear`、`list`。后处理本身住在客户端资源包里，服务端并不知道玩家是否真的加载了对应资源包——所以这个命令是"尽力而为"，没装包就什么也看不到。

**条件类型**也换了血：新增 `minecraft:match_block`（可匹配方块 ID、方块状态、方块实体 NBT、组件与组件谓词），并**删除** `minecraft:block_state_property`（功能被前者完全取代）。药水谓词重写：`minecraft:potion_contents` 现在可以按效果匹配，支持 `contains`/`count`/`size` 三种集合谓词，单个效果可匹配 `duration`、`amplifier`、`ambient`、`visible`。配方侧，`cookingtime` 不再是可选字段，烟熏炉与高炉的加速改由 `minecraft:cooking/speed_default` 数值提供器承担。

**运维侧两个硬变更**：`white-list` 默认值改为 `true`（新服务器开箱即白名单模式，第一次开服必须手动加人），以及部分服务器日志行被移除（官方建议改用 MSMP）。

## 26.4 前瞻：冰洞穴与"冻伤"

26.4 是 2026 年的冬季 drop，计划 2026 年 12 月发布（Bedrock 26.70），在 2026 年 9 月的 Minecraft LIVE 上公布。截至本文截稿（2026-11-15），它的正式名称仍以开发代号 **Fourth Drop 2026** 记录，官方计划在当天的 MCC: Absolute Zero 上揭晓名称——也就是说本文写作时名称尚未公开。

已确定的内容围绕"冰"展开：

| 类别 | 内容 | 机制要点 |
| --- | --- | --- |
| 生物群系 | 冰洞穴（Ice caves） | 生成在寒冷群系下方，主体是浮冰与方解石，地面与天花板有大片冰柱，地面偶有冰晶，不生成发光地衣 |
| 结构 | 裂隙（Crevasse） | 冰洞穴里的裂缝，覆盖一层脆冰，底部是水 |
| 方块 | 脆冰（Brittle ice） | 被踩会逐渐开裂并碎裂；冻伤者与流浪者踩不碎；不融化；水与蓝冰水平相邻时生成；只能精准采集获得 |
| 方块 | 冰柱（Icicle） | 钟乳石类方块，向下最多长 5 格；附近有强光源或在井下会融化；坠落伤害按落距缩放，落到石笋上会按跌落高度放大摔伤 |
| 方块 | 冰晶（Ice crystal） | 地面生成，发光等级 4，可贴六面，支撑方块消失就掉落，放在浮冰上方有环境音 |
| 方块 | 方解石套件 | 方解石柱/台阶/楼梯/墙，磨制方解石及其砖块变体，切石机可切 |
| 方块 | 浮冰砖、雪砖 | 浮冰砖不滑、用镐挖且不需要精准采集；雪砖只能用锹挖，否则不掉落；两者都归入硫磺方块生物的 Fast Sliding 原型 |
| 生物 | 冻伤者（Frostbite） | 僵尸在细雪里待太久转化而来（穿皮革盔甲可避免）；不陷细雪、日晒燃烧；近战带冻伤效果，远程扔冰球；水下待太久会变回僵尸 |
| 物品 | 冰球、冻伤药水、冻伤之箭 | 冰球可酿造冻伤药水；冻伤之箭用滞留型冻伤药水 + 8 支箭合成 |
| 效果 | 冻伤（Freezing） | 持续掉血并减速；皮革盔甲可免疫，着火/岩浆可抵消；亡灵、雪傀儡、北极熊、末影龙完全免疫；烈焰人、岩浆怪、炽足兽受 5 倍伤害 |
| 其他 | 唱片 "Flurry"、新进度 | 唱片由 Hyper Potions 制作，冰屋地下室箱子 30% 概率，比较器输出 7 |

技术侧，26.4 的资源包格式到 **103.0**、数据包到 **127.0**：地形顶点数据改为从 texel buffer 取，顶点打包格式变更（`terrain.vsh` 重构）；`screenquad.vsh` 改名为 `screentriangle.vsh`；云的 OIT 支持从 `clouds.fsh` 拆到 `blit_clouds.fsh`；新增 `sulfur_cube_archetype` 定义注册表，把 26.2 里硬编码的 12 种原型变成数据驱动。此外还有 `/effect`、`/fillbiome`、`/time` 的调整与登录协议改动。

## 对玩家、建筑党与整合包的实际影响

**玩家。** 26.3 是"住得更好"的一版：坐垫、草垫床、羊毛/混凝土楼梯让室内装修第一次有了完整选项。26.4 则是"走得更远"的一版：冰洞穴 + 裂隙 + 脆冰构成了一条需要准备的探险路线，冻伤效果逼你带皮革盔甲或火源。

**建筑党。** 两个 drop 加起来新增了方解石、浮冰砖、雪砖、羊毛/混凝土形状方块、白杨木全套，是 2024 年以来最大的一次调色板扩张。注意浮冰砖与雪砖的工具与掉落规则不同（镐 vs 锹），批量施工前先确认。

**整合包。** 26.3 的破坏面主要在数据包（`block_state_property` 被删、`cookingtime` 变必填、药水谓词重写、探险家地图改名）；26.4 的破坏面在渲染与顶点格式（`terrain.vsh` 重构）与登录协议。跨这两个版本升级时，最省事的路径是先把数据包按 121.0 修完，再看 127.0 的差异。

## 常见坑

1. **`white-list` 默认变 `true`**：26.3 新开的服务器，第一位玩家会被挡在门外，必须先 `whitelist add`。
2. **`/compute` 整数模式与浮点模式结果不同**：中间步骤截断，别拿它做金融级计算。
3. **`/posteffect` 看起来"没反应"**：后处理在客户端资源包里，服务端无法验证。
4. **数据包报 `block_state_property` 未知类型**：26.3 已删除，改用 `match_block`。
5. **旧探险家地图 ID 失效**：五个地图被改名，`/give` 与商店配置要同步。
6. **烟熏炉/高炉配方缺 `cookingtime`**：26.3 起必填，旧配方会加载失败。
7. **白杨树苗长出的颜色随机**：想造"纯红白杨林"只能靠反复种，或直接用命令放叶子。
8. **26.4 名称尚未公布**：截至 2026-11-15，官方只给了开发代号与内容清单，任何"正式名"说法都不可信。
