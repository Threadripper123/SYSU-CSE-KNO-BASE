## 一句话结论

铜在 Minecraft 里原本是个尴尬的材料：能做避雷针、能做装饰、能氧化，但**没有工具、没有盔甲、没有实用装备**。铜器时代一次性把它补齐成一条完整产业链——矿 → 锭 → 粒 → 工具/盔甲/马铠 → 装饰方块 → 铜傀儡 → 铜箱 → 自动分拣。更关键的是它给这套系统加了一个别的材料都没有的东西：**氧化**。铜傀儡会氧化，氧化到头会变成雕像，你的自动分拣线会自己停摆。这是 Minecraft 第一次把"维护成本"做进自动化系统里。

## 二、铜作为"材料等级"：数值到底站在哪

这是玩家最关心也最容易传错的部分。铜被刻意放在**石与铁之间**，但三项数值的定位并不一致：

| 属性 | 铜 | 参照 |
| --- | --- | --- |
| 工具伤害 | 与**石**相同 | 低于铁 |
| 工具耐久 | 高于石、低于铁 | 用铜锭合成与修复 |
| 挖掘效率 | 高于石、低于铁 | — |
| 附魔能力 | **13** | 高于钻石（10）、低于铁（14） |
| 盔甲总护甲值 | **10 点** | 高于皮革、低于金 |
| 盔甲耐久 | 高于金、低于锁链与铁 | — |
| 盔甲附魔能力 | **8** | 低于铁（9），是**所有盔甲类型里最低的** |
| 铜马铠护甲值 | **4 点** | 与世界生成概率同铁马铠一致，不能合成 |

可以看出官方的取舍：**工具适合"过渡期"，盔甲适合"能不穿就不穿"**。工具附魔能力 13 意味着它其实是个不错的附魔载体（比钻石高），但盔甲附魔能力 8 让它几乎无法成为附魔目标。这不是数值失衡，而是明确的设计信号：铜的定位是"工具与自动化"，不是"战斗装备"。

另外两件容易被忽略的事：

- **铜粒**成了独立物品：铜制装备烧炼后变铜粒，**9 粒 = 1 锭**。这让"熔掉旧装备回收"第一次有了经济意义。
- **铜马铠**不能合成，只在战利品表里以与铁马铠相同的概率出现，提供 4 点护甲值。

## 三、铜傀儡：一个会自己坏掉的物流机器人

### 3.1 怎么造

把**雕刻南瓜或南瓜灯**放在**铜块**上，并在上面生成铜傀儡，会同时生成**铜箱**。注意两点：用**刷怪蛋**生成的铜傀儡**不会**带出铜箱；铜傀儡是**被动生物**，被杀死掉落 **1–3 个铜锭**。

### 3.2 它到底怎么分类

铜傀儡的物流规则比"自动整理"四个字复杂得多，这四条例决定了你的仓库要怎么设计：

| 规则 | 具体行为 |
| --- | --- |
| 取货 | 从**铜箱**里取物品，拿在手上 |
| 送货 | 把物品放进**箱子或陷阱箱** |
| 目标判定 | **只放进空箱子，或已经含有至少 1 个同类物品的箱子** |
| 单次上限 | 一次最多搬运 **16 个**（一堆） |
| 可打断 | 它手上拿着的物品**可以被玩家拿走** |
| 开门 | 能打开**非铁门** |
| 装饰 | 铁傀儡可以给它头上放一朵虞美人，可用剪刀剪下 |

"只放空箱或已有同类"这条极为重要：它意味着铜傀儡**不会**帮你把混合箱子整理干净，只会把同类聚拢。想做分类仓库，得先手动给每个箱子放一个"样本"，它才会认路。

### 3.3 氧化：这套系统真正的成本

铜傀儡和铜块一样会氧化，可以被**打蜡**，被**闪电击中会去除氧化且不受伤**。氧化到完全阶段时，它会**变成铜傀儡雕像并定格在一个随机姿势**。用**斧头**敲雕像可以去除氧化，最终把它**复活**。

雕像的四种姿势是 **Standing（默认）、Running、Sitting、Star**，每种姿势对应**唯一的比较器信号**——这让雕像可以当"用姿势编码的红石信号源"，是个相当少见的用法。交互可以切换姿势。

这条设计链的后果很直接：**任何靠铜傀儡长期运行的自动分拣线，都必须配套打蜡或定期维护**，否则它会自己变成一尊雕像，物流静默停摆，而且不会有明显的报错提示。

## 四、铜制装饰方块：一套完整的建材线

| 方块 | 合成 | 特性 |
| --- | --- | --- |
| 铜栏杆（copper bars） | **6 个铜锭** | 会氧化、可打蜡 |
| 铜链 | **1 铜锭 + 2 铜粒** | 会氧化、可打蜡；原版"锁链"因此改名为**铁链**以作区分 |
| 铜火把 | 木棍 + 煤炭 + **铜粒** | 新光源 |
| 铜灯笼 | 铜火把 + **8 个铜粒** | 会氧化、可打蜡 |
| 铜活板门 | 配方改为 **4 铜锭**（原 6） | 产量从 2 改为 **1** |
| 避雷针 | 新增氧化与打蜡变体 | 现在也会氧化 |

这些方块共用同一套四阶段氧化（未氧化 → 斑驳 → 风化 → 氧化），因此一座纯铜建筑会随着时间自然变色，打蜡则定格。这套视觉变化是这一版最"可玩"的建材特性。

## 五、搁板（Shelf）：把快捷栏外挂到墙上

搁板是本版唯一与铜无关但影响很大的新方块：

- 用**去皮原木**合成；
- 可存 **3 组物品**；
- 被红石充能时**正面纹理改变**；
- 在充能状态下与它交互，会把它里面的物品与**快捷栏最右侧的槽位**交换；
- **多块搁板可以连起来**，从而一次替换超过 3 个快捷栏槽位。

这相当于给建筑加了一个"红石切换装备栏"的接口：配合按钮与红石线，可以做出一按换全套工具的工作台墙。对整合包作者，这也是一个很适合做"多套装备预设"的原生组件。

## 六、其它改动

- **所有染料纹理重做**：每種染料现在有独有形状，并统一在棕色底板上呈现。官方说明这是为了在保持色盲可访问性的同时增强整套染料的视觉一致性——这是少数把无障碍写在改动说明里的更新。
- **铁傀儡**会主动给铜傀儡戴花。
- 基岩版侧：1.21.112 是 PS5 专属热修，1.21.120 重做暂停菜单，其余多为修 bug。

## 六点五、发布期的社区活动

铜器时代的宣传动作也是这批 drop 里最有"参与感"的一次：官方在 2025-08-29 宣布 **Copper Collection（铜矿收集）社区挑战**，持续 4 天，到 9 月 2 日结束。目标由基岩版玩家共同完成——**累计挖掉 5000 万（50,000,000）个铜矿石**。达成后发放一个角色创建器头饰；另外还有一件 "Oxidized Copper Collector" 发给协助宣传的创作者。

把"集体挖矿"做成发布活动，恰好对应这一版的主题：铜从一个边缘材料变成了需要大量开采的主干材料。

## 七、技术侧：影响所有整合包的一处格式变更

这一版有一个比内容本身更容易让人卡住的改动：

**从 25w31a 起，`pack.mcmeta` 的 `pack_format` 字段被 `min_format` 与 `max_format` 取代**，数据包与资源包**都**适用。1.21.9 的推荐写法是：

```json
{
  "pack": {
    "description": "Example datapack for Minecraft 1.21.9",
    "min_format": 88,
    "max_format": 88
  }
}
```

实际影响：

1. 仍只写单个 `pack_format` 的旧包，需要迁移到 `min_format`/`max_format`，否则在 1.21.9+ 上会落在不受支持的格式区间。
2. 资源包格式跳到 **69.0**、数据包跳到 **88.0**，这两个数字都是带小数的写法（`69.0`/`88.0`），不再是纯整数。
3. 服务端若装载旧数据包，升级到 1.21.9 前必须先在测试环境跑一遍，否则可能出现"包加载失败但服务器照常启动"的隐性故障。

对模组开发者，1.21.9 也是渲染与客户端结构变化较大的一版（铜傀儡、搁板都带新的模型与状态），跨版本移植时需要重新核对模型与方块状态。

## 八、对服主、整合包与红石玩家的建议

- **红石/自动化玩家**：铜傀儡 + 铜箱可以做低成本分拣，但**必须打蜡**；雕像的比较器信号是一个可编程的姿势开关。
- **建筑玩家**：铜栏杆、铜链、铜灯笼、铜火把补齐了"铜系建材"，配合四阶段氧化能做时间感建筑。
- **服主**：升级到 1.21.9 前先确认数据包已改为 `min_format`/`max_format`；旧世界不会自动给已有铜块打蜡。
- **整合包作者**：铜工具适合做"石→铁"之间的过渡，铜盔甲基本只适合当装饰或前期过渡；搁板可以替代部分"装备切换"类模组。
- **PVP 服**：铜盔甲附魔能力 8，几乎不可能成为主流装备，不必担心数值膨胀。

## 九、常见坑

1. **刷怪蛋生成的铜傀儡没有铜箱**，要铜箱必须用"南瓜 + 铜块 + 生成"的建造方式。
2. **铜傀儡只往空箱子或已有同类物品的箱子放**，混合箱子不会自动整理。
3. **不打蜡的铜傀儡最终会变成雕像**，物流会静默停止。
4. **铜活板门产量从 2 变 1**，旧合成计算要重算。
5. **"锁链"已改名"铁链"**，配方书与旧攻略的命名会对不上。
6. **铜傀儡能打开非铁门**：把分拣区用木门、栅栏门围起来是关不住它的，要么用铁门，要么用方块堵死。
7. **铜盔甲附魔能力最低**，别在它身上浪费经验。
8. **铜马铠不能合成**，只能靠战利品。
