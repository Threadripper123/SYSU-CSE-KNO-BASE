# MC-03 1.21 Tricky Trials 深度拆解：试炼密室、旋风人、重锤、合成器

> 主题库：Minecraft 现代版本与模组（2023–2026）　｜　源文件：（纯文本条目）　｜　5,319 字符　｜　38 个片段　｜　更新于 2026-11-15
> 资料截至 2026-11-15；覆盖 2023-11 至 2026-11，重点 2024–2026。

**一句话结论**：Tricky Trials 不是一个「加内容」的更新，而是一次**循环设计**的更新——它造了一个可重复刷的地下副本（试炼密室），用「波次刷怪 → 掉钥匙 → 开宝库」把战斗、探索、收益串成闭环，再用「不祥事件」给愿意加难度的玩家一条高收益支线；同时在红石侧补了合成器与铜灯两个真正改变自动化玩法的方块。重锤是这条循环的奖励顶点，也是全版本唯一吃「下落高度」的武器。

## 一、版本事实先摆清楚

| 项目 | 数值 |

| 类别 | 大版本（major update），非 drop |
| Java 要求 | Java 21 及以上，且必须 64 位系统 |
| 资源包格式 | 34 |
| 数据包格式 | 48 |
| 新增画作 | 20 幅 |
| 官方定位 | combat、adventures、tinkering（战斗、冒险、鼓捣） |

官方在 2023-10-15 的 Minecraft Live 上首次公布，2024-04-26 的 Minecraft Monthly 才揭晓「Tricky Trials」这个名字。1.21 是第一个要求 64 位系统与 Java 21 的**大版本**（1.20.5 是小版本里第一个）。

## 二、试炼密室：把「副本」做进主世界

试炼密室（trial chambers）是罕见的地下结构，生成在 Y = -40 到 -20 之间，主世界几乎所有生物群系都可能有——唯独起始点不会生成在深暗之域（deep dark），但如果结构够大、贴着深暗之域，其余部分仍可能伸进去。

材质上它几乎只用两套方块：铜（含斑驳、风化、氧化与打蜡共 8 种状态）与凝灰岩砖系列。这不是审美选择，而是解法提示——铜的氧化状态与凝灰岩的硬度，暗示了这一区域的「工业废墟」气质。

结构里散布三类核心方块：试炼刷怪笼（trial spawner）、宝库（vault）、以及各类战利品箱与陷阱。它也是**全游戏唯一自然生成旋风人的地方**，因此是旋风棒的唯一产地。

一个常被忽略的设计：试炼密室不需要钥匙进门。它是开放的，任何人都能挖进去；真正的门槛在里面的「刷怪笼 → 钥匙 → 宝库」链条上。这让它既能当探索内容，也能当多人服务器的公共副本。

## 三、试炼刷怪笼：波次、缩放与 30 分钟冷却

试炼刷怪笼的行为和传统刷怪笼完全不同：

- **按波次刷**：它一次召唤一批怪物，全部清完后才结算奖励，然后**停用 30 分钟**。
- **按人数缩放**：附近的生存/冒险模式玩家越多，刷出的怪越多、奖励也越多。这是它鼓励组队的核心机制。
- **只掉消耗品与钥匙**：清完波次会弹出消耗类物品，和/或试炼钥匙（trial key）。钥匙不是必掉，所以「刷一轮必得一把钥匙」是错的。
- **可被不祥化**：在不祥事件期间，普通试炼刷怪笼会转成不祥试炼刷怪笼——**即使它正在冷却中**。这一点很多人不知道，导致以为冷却期就绝对安全。

从设计角度看，30 分钟冷却是个很聪明的数字：它足够长，防止无限刷取；又足够短，让一个四人小队跑完整个密室后，回到起点时第一批笼子刚好快好了。

## 四、宝库与钥匙：每人一次，不是每次一次

宝库（vault）用试炼钥匙解锁，弹出战利品。关键规则只有一句：**同一座宝库可以被任意多玩家开启，但每个玩家对同一座宝库只能开一次**。

这条规则直接决定了多人服的玩法：宝库不是「抢」，而是「各开各的」。四个人进同一间密室，每人各自用钥匙开同一座宝库，各拿一份——但如果同一个人想再开，必须去另一座宝库。

不祥宝库（ominous vault）是它的强化版，需要不祥钥匙，产出更好，也是**重锤核心（heavy core）的唯一来源，掉率 7.5%**。这意味着重锤在正常游戏里是稀缺品：想要一把，平均要开十几次不祥宝库。

## 五、普通循环 vs 不祥循环

| 环节 | 普通 | 不祥 |
|---|---|---|
| 触发方式 | 直接进入 | 身带不祥之兆（Bad Omen）进入，或在密室内喝不祥之瓶 |
| 刷怪笼 | 普通试炼刷怪笼 | 转为不祥试炼刷怪笼，怪穿高阶装备 |
| 产出钥匙 | 试炼钥匙 | 有概率出不祥钥匙 |
| 宝库 | 宝库 | 不祥宝库（含 heavy core，7.5%） |
| 风险 | 低 | 高（怪更强、装备更好） |

不祥事件（ominous event）本质是「不祥之兆」状态效果触发的一套分支。它把「我要更难」变成一个可主动选择的开关：喝不祥之瓶，或者在袭击后带着不祥之兆进来。这条设计后来被沿用到了 1.21 之后的多个 drop 里。

## 六、旋风人：会跳、会反弹、只怕风弹

旋风人（breeze）是试炼刷怪笼召唤的敌对生物，体型高 1.77 格、宽 0.6 格。三个特征决定了它的打法：

1. **靠跳跃位移**：攻击时会大距离跳跃，所以它不是在原地射击的炮台，而是会绕后的游击单位。
2. **发射风弹（wind charge）**：风弹会把玩家击退、也能引爆/推动某些方块交互。
3. **反弹一切投掷物，除了风弹**：这一条最反直觉——弓箭、三叉戟、雪球打上去会被弹开，唯有风弹能穿过它的防御逻辑。也就是说，常规远程对它基本无效，要么近战，要么用风弹反制。

击杀后掉落旋风棒（breeze rod），这是合成风弹与重锤的必需材料。由于旋风人只在试炼密室生成，**旋风棒无法通过刷怪塔自动化**——这是它长期保值的根本原因。

## 七、重锤：唯一吃「下落高度」的武器

重锤（mace）是 1.21 的战斗核心奖励，属性如下：

| 属性 | 数值 |
|---|---|
| 稀有度 | 史诗（Epic） |
| 攻击速度 | 0.6 |
| 攻击距离 | 3 |
| 附魔能力 | 15 |
| 合成 | 重锤核心 + 旋风棒 |
| 特殊 | 下落攻击（smash），伤害随下落高度递增 |

机制上有两个关键点。第一，**下落攻击的伤害随下落距离增长，理论上没有上限**，所以「从高处跳下砸」是它的正确用法，而不是站着平A。第二，**成功命中后，之前累积的下落伤害会被免除**——也就是说砸中了就不摔伤，砸空了照样摔。

配套的三个新附魔也很明确地服务于这个机制：

| 附魔 | 最高等级 | 作用方向 |
|---|---|---|
| Density（密度） | V | 提升下落攻击伤害 |
| Breach（破甲） | IV | 无视部分护甲 |
| Wind Burst（风爆） | III | 命中后把玩家弹起，便于连击 |

Wind Burst 是最能改变操作手感的一个：命中后向上弹起，意味着你可以连续砸同一目标，形成「砸—弹—再砸」的循环。它也是唯一能让重锤从「一次性大招」变成「可持续输出」的附魔。

## 八、合成器：把合成表变成红石元件

合成器（crafter）是一个低容量存储方块：给它红石信号，它就用内部物品按配方合成，把产物弹到世界里，或推进它朝向的容器。

真正让它区别于「自动合成台模组」的是**槽位可单独锁定**：你可以把某些格子锁死，让漏斗之类的东西灌不进去，但**不影响合成配方本身**。这一条解决了自动化里最烦的问题——原料按固定比例配比时，多灌一格就全乱。

实际用法通常是：漏斗按顺序供料 → 锁定多余槽位 → 红石脉冲触发 → 产物进箱子。配合观察者做脉冲，可以搭出真正无需人干预的生产线。它对红石社区的意义，可能比重锤对战斗社区更大。

## 九、铜灯：脉冲开关，亮度随氧化下降

铜灯（copper bulb）是一个发光方块，规则只有两条：**收到红石脉冲就切换开关状态**（不需要持续供电），**亮度随氧化程度下降**。

| 氧化状态 | 点亮时亮度 |
|---|---|
| 未氧化 | 15 |
| 斑驳（exposed） | 12 |
| 风化（weathered） | 8 |
| 氧化（oxidized） | 4 |

打蜡（waxed，用蜜脾）后不再继续氧化，功能不变。这条设计把「装饰老化」变成了一个真实的工程约束：想要满亮度就得打蜡，想要「老旧感」就让它氧化到 4。红石玩家因此第一次有了「亮度可调且状态自保持」的灯——比红石灯省事，因为红石灯必须持续供电。

## 十、其余内容速览

- **沼骸（bogged）**：骷髅变种，射毒箭，主要由试炼刷怪笼召唤，是试炼密室的常见敌人。
- **四种新药水**：Wind Charging（蓄风）、Weaving（织网）、Oozing（渗浆）、Infestation（寄生），每种都有普通/喷溅/滞留/箭矢四形态。
- **新陶片与旗帜图案**：Flow、Guster、Scrape 三种陶片，Flow 与 Guster 两种旗帜图案。
- **盔甲纹饰**：Flow 与 Bolt 两种。
- **试炼探险家地图（Trial Explorer Map）**：指向最近的试炼密室。
- **20 幅新画**：单次更新里画作数量最多的一次。
- **铜建筑全套**：凿纹铜、铜格栅、铜门、铜活板门，每种各 8 个氧化/打蜡变体。

## 十一、对玩家、整合包与红石社区的影响

**玩家**：1.21 给了中后期一个「可反复刷、有明确收益曲线」的玩法。此前的中后期内容要么是一次性结构（要塞、林地府邸），要么是纯挂机（刷怪塔）。试炼密室是第一个「需要操作、可以重刷、收益随人数缩放」的官方副本。

**整合包作者**：试炼密室成了天然的「中期资源节点」。很多包会把重锤核心、旋风棒设为任务线卡点——因为它们无法自动化，只能靠打。反过来，如果包改了战利品表，要记得不祥宝库与普通宝库是两张表，改一张不会影响另一张。

**红石社区**：合成器 + 铜灯是这次更新真正的长期遗产。合成器让「全自动合成」不再必须依赖模组，铜灯让「状态自保持的灯」成为原版方块。两者叠加，可以直接搭出无模组的自动农场—加工—仓储链路。

## 十二、常见坑

1. **以为宝库能反复刷**：每个玩家对同一座宝库只能开一次，换人才能再开。
2. **以为清完波次必掉钥匙**：钥匙是概率产出，不是保底。
3. **以为冷却期绝对安全**：不祥事件能把冷却中的刷怪笼直接转成不祥刷怪笼。
4. **拿弓箭打旋风人**：除风弹外的投掷物都会被弹开，远程基本无效。
5. **站着平A重锤**：它的伤害来自下落高度，不跳起来砸就是一把慢速低伤武器。
6. **以为铜灯要持续通电**：它是脉冲切换，红石火把常亮反而不会切换状态。
7. **忘了给铜灯打蜡**：氧化到 4 级亮度后，照明工程会直接失效。
8. **在普通宝库刷重锤核心**：heavy core 只在不祥宝库产出，掉率 7.5%。

- 1.21 的协议号与数据版本未逐一核实，本文未给出具体数字。
