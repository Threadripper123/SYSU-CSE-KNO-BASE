# 26.2 Chaos Cubed：内容、机制与模组影响

> 资料截至 2026-11-15；覆盖 2023-11 至 2026-11，重点 2024–2026。

## 一句话结论

26.2「Chaos Cubed」是 2026 年内容量最大的一个 drop：新增硫磺洞穴生物群系、硫磺/朱砂两套建筑方块、会吸收方块并改变物理属性的硫磺方块生物，同时把 Vulkan 渲染后端、好友列表、Minecraft Server Management Protocol 3.0.0 一起推上台面。它的内容面向玩家，改动面却直指渲染模组、材质包与世界生成数据包——**这是 2026 年最容易被"看起来只是加了个生物"低估的一版**。

## 硫磺洞穴：一个会"漏气"的生物群系

硫磺洞穴（Sulfur caves）是地下生物群系，生成在地下以及山体内部，岩层呈硫磺与朱砂的条带状分布。它有几个不寻常的设定：

- 刷的是**洞穴蜘蛛**而不是普通蜘蛛，而硫磺方块生物本身占的是敌对生物上限（hostile mob cap），却按被动生物的行为活动。
- 群系内生成**硫磺池**，池里是 Potent sulfur（活性硫磺）。
- 如果这个群系被地形抬升暴露到地表，地表会按完整的地下地貌生成，而不是只铺一层草方块——这是刻意设计，避免"洞穴生物群系露头就破功"。
- 地表的对应特征是**硫磺泉**（Sulfur spring），由硫磺、活性硫磺与岩浆块组成，分小、中、大、特大四档尺寸。

方块侧是两套完整的建筑体系。**硫磺**与**朱砂**各自能切出楼梯、台阶、墙，再加工成磨制（polished）、砖（bricks）与雕纹（chiseled）三种变体——和过去铜、深板岩的处理方式一致，属于"给建筑党的标准配置"。**硫磺尖刺**（Sulfur spike）是洞穴里的钟乳石/石笋：天花板生成向下、地面生成向上，可以拼接加长，尖端相邻会自动合并（潜行放置则不合），失去支撑会掉落或崩塌，被掉落的尖刺砸到会受伤，扔出的三叉戟能打断它，4 个尖刺可合成 1 个硫磺块。

真正的新机制在**活性硫磺**上，它把"水下气体"做成了一套可玩的物理：

| 条件 | 现象 | 关键数值 |
| --- | --- | --- |
| 单独放置于水下 | 冒泡，气泡上浮至上方 4 格水源 | 4 格 |
| 下方无水、上方有水源 | 水面生成催吐毒气云 | 扩散半径 3 格 |
| 下方是岩浆块、上方 1–4 格水 | 形成间歇泉，周期性喷发 | 间隔 50 秒 |
| 喷发时 | 把上方实体顶起 | 持续 4–5 秒 |
| 喷发高度 | 每格水约抬升 7 格 | 7 格/水格 |
| 下方是岩浆源 | 持续喷发（声音更闷） | 持续 |
| 喷发开始/结束 | 发出可被幽匿感测体探测的 game event | 2 次 |

毒气会穿过无碰撞的水浸方块与其他无碰撞方块扩散；喷发羽流同样能穿过无碰撞方块（脚手架因此成了"站在喷口上方但不中毒气"的替代方案）。喷发与冷却时间按方块坐标随机化，**替换方块不会重置**——这一点对红石装置很关键，等于给了每口泉一个固定的"相位指纹"。

## 硫磺方块生物：会吸方块的史莱姆

硫磺方块生物（Sulfur cube）大型 8 点生命、小型 4 点生命，跳跃移动，死亡分裂成两个小的、无掉落物；小的可以用黏液球引诱并喂大；大的可以用空桶装成"硫磺方块生物桶"。

它的核心交互是**吸收方块**：玩家手持方块右键，它会吸进去并关闭 AI；手持剪刀右键可以把方块剪下来、恢复 AI。吸了方块之后，它会跟随手持同类方块的玩家，也会自己去找地上的方块物品吸。吸了方块的形态下，它免疫摔落、玩家与爆炸伤害，变成可以被拳打、推动的"物理球"，但仍然怕岩浆。

吸收哪种方块，决定它进入哪个 **archetype（原型）**，而原型直接改写它的速度、弹性、地面摩擦、空气阻力与是否浮水：

| 原型 | 手感 | 触发方块 |
| --- | --- | --- |
| Regular | 中速、中弹、中摩擦、低阻力、浮水 | 泥土、泥 |
| Bouncy | 高速、高弹、中摩擦、低阻力、浮水 | 木质方块 |
| Slow Bouncy | 低速、高弹、中摩擦、中阻力 | 石质与矿物 |
| Fast Flat | 高速、低弹、中摩擦、低阻力 | 有机方块 |
| Slow Flat | 低速、低弹、中摩擦、中阻力 | 金属方块 |
| Light | 低速、高弹、中摩擦、高阻力、浮水 | 羊毛 |
| Fast Sliding | 高速、无弹、低摩擦、低阻力 | 冰类方块 |
| Slow Sliding | 低速、无弹、低摩擦、低阻力 | 蘑菇方块 |
| High Resistance | 极慢、低阻低弹高摩擦 | 灵魂沙、灵魂土 |
| Sticky | 高尔夫球手感 + 极高摩擦、零弹 | 蜜脾块 |
| Explosive | 近似 Regular、阻力略高 | TNT |
| Hot | 近似 Regular、接触伤害 | 岩浆块 |

Explosive 原型值得单独说：吸入的 TNT 可被红石、火源（含打火石发射器）或附近爆炸点燃；红石/火引爆引信 **6 秒**，爆炸引爆则是 **0.75–3 秒**的随机引信。已点燃的状态下不能用桶装、不能受伤、不能剪；爆炸后不分裂小方块，本体直接消失。实体数据里有 `fuse` 字段，非爆炸型或未点燃时为 `-1`。

发射器也接入了这套系统：可以给硫磺方块生物装/换方块、用剪刀剪下方块、从桶里放出生物（但不能反过来装桶）。

## Vulkan、反向深度与 shader 合并

26.2 把渲染后端的第一块砖放下来了：

- **实验性 Vulkan 后端**。要求 Vulkan 1.2 + dynamic rendering + push descriptors，旧硬件与旧驱动回退 OpenGL；macOS 通过 MoltenVK 翻译到 Metal；Vulkan 下优先使用独显（OpenGL 下不是这样）；F3 的 `system_specs` 段能看到当前后端。官方明确说它"可能不够快、不够稳"。
- **反向深度缓冲**，用于缓解大多数硬件上的 Z-fighting。
- **粒子超限策略**改成随机跳过渲染，而不是删掉已存在的粒子——视觉上更"均匀"，但截图对比会不稳定。
- **文本 shader 大合并**：`core/rendertype_text`、`rendertype_text_see_through`、`rendertype_text_intensity`、`rendertype_text_intensity_see_through`、`rendertype_text_background`、`rendertype_text_background_see_through` 六个合并成 `core/text` 与 `core/text_background`，差异改用 `IS_GUI`、`IS_SEE_THROUGH`、`IS_GRAYSCALE` 三个 define 表达。

资源包格式升到 **88.0**，数据包升到 **107.1**。同时发生的一批"去特殊模型化"改动，是 26.2 对材质作者最不友好的地方：

- 床（bed）与告示牌/悬挂告示牌改为**方块模型**渲染，不再走内置实体模型；床不再渲染内侧面，床的方块实体被移除。
- `minecraft:standing_sign`、`minecraft:hanging_sign`、`minecraft:bed` 三种特殊模型类型被删除。
- `minecraft:beds` 与 `minecraft:signs` 两个贴图图集被移除，合并进 `blocks.png-atlas`。

换句话说，任何靠"实体模型 + 独立图集"改床和牌子的旧材质包，在 26.2 上要么失效要么错位。

## 社交与运维：Friends list 与 MSMP 3.0.0

**好友列表**是 26.2 的"非游戏性"主线：标题屏与暂停菜单新增 Friends 按钮，快捷键 `O`，界面分 Friends 与 Requests 两个 tab，状态只有 `Offline`、`Online`、`In a world` 三种。打开界面时每分钟轮询一次，否则每 5 分钟一次；好友请求、请求被接受等事件用 toast 提示（有皮肤时显示头像）；请求角标最多显示 5 个，超出显示"more"。功能本身可在 Online Options 里关闭，但按钮始终可见——点进去是开启引导。Presence 有三档：`All`、`Limited`（只显示在线/离线）、`None`（对好友显示为离线）。

**服务端**侧：

- MSMP 升到 **3.0.0**，管理服务器先于 Minecraft 服务器启动，因此世界加载/升级期间也能收到心跳，`rpc.discover` 与 `notification/server/status` 在这段时间可用，其他方法会报错。
- `server.properties` 新增 `chat-spam-threshold-seconds` 与 `command-spam-threshold-seconds`，默认都是 `10`，设为 `0` 可关闭对应类型的踢出。计数规则是"每条消息 +1 秒，每 tick 减 1/20 秒"，阈值 10 意味着 1 秒发 11 条、2 秒发 14 条、10 秒发 21 条就会被踢。
- 新增 `/unpublish`，用于关闭已开放的局域网联机。

属性系统也扩了一组"物理旋钮"，这些是给数据包与模组用的公共接口：`minecraft:air_drag_modifier`（0–2048，默认 1）、`minecraft:bounciness`（0–1，默认 0）、`minecraft:friction_modifier`（0–2048，默认 1）、`minecraft:name_tag_distance`（0–512，默认 64）、`minecraft:below_name_distance`（0–512，默认 10）；同时 `knockback_resistance` 的最小值放宽到 `-2.0`。

## 对模组、材质与数据包的实际影响

**渲染类模组。** 26.2 同时引入 Vulkan 实验后端与反向深度缓冲。现有优化模组绝大多数是围绕 OpenGL 管线写的（自己的 chunk 渲染、自己的 shader 注入点），在 Vulkan 后端下要么不生效、要么直接崩。务实的做法是先留在 OpenGL 后端，等 Vulkan 从"实验性"转正再迁移；同时注意文本 shader 合并会让任何替换 `rendertype_text*` 的 shader 包失效。

**材质与模型类。** 床、告示牌去实体模型化 + 图集合并，是这次最硬的破坏面。检查清单很短：`pack.mcmeta` 是否 ≥ `88.0`、有没有引用 `minecraft:beds`/`minecraft:signs` 图集、有没有自定义 `standing_sign`/`hanging_sign` 模型。

**世界生成数据包。** 107.1 里有两处重命名会直接让旧包报错：`pointed_dripstone` → `speleothem`、`dripstone_cluster` → `speleothem_cluster`（字段也一并改名，如 `chance_of_taller_dripstone` → `chance_of_taller_generation`）；`noise_gradient` 地表规则被重写，旧写法要改用 `noise_threshold` 复现；`tree` 特征的 `below_trunk_provider` 不再有默认值。新增的 `sequence`、`template` 特征类型与 `interval_select` 密度函数则是新工具。

**社交类模组。** 官方好友列表占了"社交图谱"这个生态位，第三方好友/在线状态模组会与它在 UI 与 Presence 语义上重叠；这不是技术冲突，是产品冲突。

## 常见坑

1. **以为 26.2 只加了一个生物**：实际它同时改了渲染后端、图集、特殊模型、世界生成字段、服务端管理协议。
2. **在 Vulkan 后端上跑渲染优化模组**：先切回 OpenGL 验证，再判断是模组问题还是驱动问题。
3. **旧材质包的床/牌子错位**：不是贴图路径错，是渲染路径从实体模型换成了方块模型。
4. **数据包报 "unknown feature type pointed_dripstone"**：26.2 已改名 `speleothem`。
5. **服务器踢人阈值被拆成两个**：原来只有一个合并阈值，现在聊天与命令分开算，误判时要分别调。
6. **活性硫磺的泉眼相位固定**：拆掉重放不会重置喷发节奏，做自动化时要按坐标而不是按"重放"来对齐。
7. **硫磺方块生物占敌对上限**：把它当宠物养在基地，会挤压其他敌对生物的生成额度。
