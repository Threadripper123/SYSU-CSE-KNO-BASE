# MC-05 2025 夏：Chase the Skies——把飞行坐骑下放给普通玩家

> 资料截至 2026-11-15；覆盖 2023-11 至 2026-11，重点 2024–2026。

## 一句话结论

"追逐天空"做了一件此前没人做过的事：把飞行从末地船精英掉落（鞘翅）改成一条**可养殖、可繁殖、可四人共乘**的产业链。快乐恶魂不是"更好用的鞘翅"，而是一个会跟随、会认家、需要长大的活体载具。同一版本的另一半价值在多人体验——定位条把"队友在哪"从语音沟通问题变成了 HUD 上的箭头。对服主和整合包作者来说，真正要重做配置的是拴绳、鞍、剪刀这一整套连锁改动。

## 二、快乐恶魂：一条完整的三阶段产业链

### 2.1 从方块到坐骑

快乐恶魂不是直接刷出来的，必须走完"方块 → 幼崽 → 成年体"三段：

| 阶段 | 获取/触发方式 | 关键数值 |
| --- | --- | --- |
| 干瘪恶魂（方块） | 灵魂沙峡谷中自然生成于下界化石旁；可与猪灵以物易物；也可用**灵魂沙 + 8 个恶魂之泪**合成 | 放在灵魂沙或灵魂土上会发出干涩声响 |
| 补水 | 把干瘪恶魂放进**水**里 | 外观随浸泡时间变化 **3 次**（表情随之改变），约 **20 分钟**后变成恶魂幼崽 |
| 恶魂幼崽（Ghastling） | 补水完成后生成 | 体型 **0.95 格**；**不会溺水**；需 **20 分钟**长大，喂雪球可加速；不能装备挽具 |
| 快乐恶魂（成年） | 幼崽长大后 | 体型 **4.0 × 4.0 格**；生命 **20（10 颗心）**；移动速度 **0.05**；可装备挽具、最多 **4 人**共乘 |

反向操作会回退：**破坏干瘪恶魂方块、或把水抽走**，它会退回原始状态。这意味着你不能把它当"半成品"摆在岸上晾着。

### 2.2 挽具与骑乘

挽具（Harness）是快乐恶魂的"鞍"，但更宽：**16 种颜色**，由所用作羊毛颜色决定，合成材料是**皮革 + 玻璃 + 羊毛**。装备后护目镜会放下，玩家可以驾驶它飞行；它也能像潜影贝一样被**站在上面**。

几个容易被忽略的规则：

- **只有成年体**能装备挽具并被骑乘，幼崽不行。
- 剪刀可以取下挽具（与鞍、马铠、地毯同一套规则）。
- 快乐恶魂**不受速度效果影响**——加速度药水没用。
- 生命恢复默认 **每 30 秒 1 点**；在下雨、下雪，或停留在主世界 **Y 187–196（云层高度）** 时恢复更快。
- 死亡时掉落已装备的挽具，并被玩家或已驯服狼杀死时掉落 **1–3 点经验**；幼崽不给经验。

### 2.3 "认家"机制

快乐恶魂有一个 home 点，初始为生成位置，并在以下事件发生时**更新为当前位置**：

1. 装备或取下挽具；
2. 拴绳被解开；
3. 不再被玩家用雪球或挽具吸引。

活动半径随之变化：**未装备挽具 64 格**，**已装备挽具与幼崽 32 格**。这条规则直接决定了"把恶魂停在基地哪里"——想让它在附近待命，就别老给它解拴绳。

### 2.4 幼崽的行为

幼崽会偶尔跟随 **16 格**内的玩家、村民，以及任何被动或中立的陆地动物；靠近时速度 **×1.1**，进入 **5 格**内停止。这个"跟随但会腻"的设计，让它在基地里像一个会乱跑的宠物，而不是一个待激活的道具。

### 2.5 成本换算

如果完全不靠交易，从零做一只成年快乐恶魂需要：**8 个恶魂之泪**（等于至少 8 次恶魂击杀，且恶魂之泪本身是掉落物）+ 约 **20 分钟**补水 + 约 **20 分钟**成长。也就是说，第一只的边际成本主要是时间，第二只之后可以靠繁殖与雪球加速压低。这是它和鞘翅最大的设计差异：鞘翅是"一次性奇观"，快乐恶魂是"可以开牧场的载具"。

### 2.6 与鞘翅的分工

把快乐恶魂当成"鞘翅替代品"会误判它的定位。两者解决的是不同问题：

| 维度 | 鞘翅 | 快乐恶魂 |
| --- | --- | --- |
| 获取方式 | 末地船的一次性拾取 | 可复制：8 个恶魂之泪 + 约 40 分钟成长 |
| 载客量 | 单人 | 最多 4 人共乘 |
| 使用形态 | 滑翔，靠高度换距离 | 悬停与自由升降，可被站在上面当平台 |
| 恢复方式 | 依赖外部修补 | 缓慢自愈（每 30 秒 1 点），天气与云层高度可加速 |
| 团队价值 | 个人机动 | 移动基地：载人、载物、当落脚点 |

换句话说，鞘翅给的是"我一个人能飞多远"，快乐恶魂给的是"我们一群人能把家搬到哪"。多人服里后者往往更值钱，这也是为什么它的成本被设计成"时间换数量"而不是"探索换唯一"。

## 三、定位条：多人玩法的默认体验被改写

定位条（Locator Bar）是 HUD 上的新元素，**取代经验条的位置**——但在获得或失去经验时、以及打开铁砧或附魔台界面时，经验条会短暂回来。

它的行为规则相当细：

| 规则 | 具体表现 |
| --- | --- |
| 显示条件 | 多人世界中开启对应 gamerule 后，每位玩家都会看到；单人世界不显示 |
| 水平范围 | 相机朝向 **120°** 内的目标显示彩色标记 |
| 垂直提示 | 目标在视口上方或下方超过 **30°** 时，标记上出现上下箭头 |
| 距离表现 | 离得越远，图标越小（同一图标有多档精灵） |
| 不可见对象 | 旁观模式玩家 |
| 主动隐藏 | 潜行、戴头盔或雕刻南瓜、拥有隐身效果 |
| 管理员控制 | 地图作者与服主可以关闭 |
| 扩展用法 | 不只玩家：实体只要 `waypoint_transmit_range` > 0 就会被追踪；颜色与样式可用 `/waypoint` 命令改；样式来自资源包的 `waypoint_style` 目录 |

两个属性是这套系统的核心：**`waypoint_transmit_range`**（谁能被看见，玩家与实体都适用）和 **`waypoint_receive_range`**（谁能看见，只对玩家生效）。实体数据里还存 `locator_bar_icon`，包含 `color`（32 位有符号整数，按全不透明处理）与 `style`（资源包 `waypoint_style` 里的样式名）。

对 PVP 服务器，这条改动含义明确：**潜行现在是"从地图上消失"的手段**，但潜行时移动速度受限，于是"隐蔽移动"变成一个真实的取舍，而不是免费的隐身。

## 四、拴绳、鞍、剪刀：一次连锁重做

这三个物品的改动必须放在一起看，因为它们互相咬合：

| 物品 | 改动 |
| --- | --- |
| 拴绳 | 合成改为 **5 根线**（原来的粘液球位置换成第 5 根线）；**实体可以拴住实体**；剪刀可剪断（含装剪刀的发射器）；绷断距离提高到 **12 格**；绷断时发出音效 |
| 鞍 | 可用 **3 皮革 + 1 铁锭**合成；剪刀可从生物身上取下（**有骑乘者时不可**，**劫掠兽不可**）；**发射器不再能装备鞍**；不再生成于怪物房、远古城市、沙漠神殿、丛林神庙、要塞祭坛的箱子（这些箱子改为生成 **1–5 个皮革**） |
| 剪刀 | 可取下鞍、马铠、挽具、地毯；可剪断拴绳；**玩家潜行时不能取**；装剪刀的发射器**不能**取这些装备 |
| 胡萝卜 | 现在可用于**驯服、治疗、催熟**马、驴、骡 |

这套改动的实际后果是一张路线图的重画：过去"找鞍"要跑五个结构，现在只要 3 皮革 + 1 铁；过去"拴绳只能拴生物到栅栏"，现在可以生物拴生物，运输与农场设计多了一种解法；过去"装备只能加不能减"，现在剪刀成了通用拆卸工具，但潜行状态下失效——这条限制是为了防止误拆。

## 五、视听与图形

- **Vibrant Visuals**：新的默认可选图形档，位置在"简单/流畅"与"精美"之上；包含像素级阴影、定向光照、水面焦散等。**Java 版当时计划后续推出**（这一点容易被误读成"Java 版已上线"）。
- **五首新背景音乐**，全部由 Amos Roddy 作曲：Lilypad（冰封山峰与树林）、Below and Above（樱花树林）、O's Piano（繁茂洞穴）、Broken Clocks（森林）、Fireflies（沙漠）。这五首也会在标题画面播放。
- **两张新唱片**："Tears"（Amos Roddy）由**玩家反弹恶魂火球击杀恶魂**掉落；"Lava Chicken"（Hyper Potions）通过**杀死骑着鸡的小僵尸**获得。后者实际在 1.21.7 才加入。
- **画作 "Dennis"**：3×3，作者 Sarah Boeving，同样 1.21.7 加入。
- **云的重做**：纹理分布改变，缝隙更多更小、形状更接近一致的椭圆，某一段纹理里还藏了一张**苦力怕脸**；云的渲染距离提高。
- **恶魂纹理分辨率翻倍**，以匹配新的快乐恶魂。
- **溅射药水**：效果时长与强度现在**随离爆点的距离线性衰减**；直接命中实体才拿到完整时长与强度。

## 六、对服务器、整合包与开发者的影响

- **多人服**：定位条默认开启会改变 PVP 与探索体验，建议在配置里明确写清是否关闭；潜行、头盔、隐身成为"反侦察"三件套。
- **空岛与早期生存**：快乐恶魂让"可再生飞行"提前到恶魂农场可用的阶段，替代了必须打末地船的路径；恶魂之泪因此从"酿造材料"变成"载具材料"，价格会上涨。
- **鞍的合成化**：早期骑乘门槛降低，但五个结构的箱子战利品表改变，旧攻略与旧跑图路线全部失效。
- **数据包/资源包**：`waypoint_style` 目录、`/waypoint` 命令、`waypoint_transmit_range`/`waypoint_receive_range` 属性是这一版新增的扩展点；1.21.6 的资源包格式跳到 **63**、数据包跳到 **80**，跨版本挂载要改 `pack.mcmeta`。
- **基岩版**：1.21.91–1.21.94 连续修 bug，1.21.100 加入 "The Void" 超平坦预设并带入铜器时代的实验性内容。

## 七、常见坑

1. **幼崽不能装挽具**：必须等约 20 分钟长大，喂雪球可以缩短。
2. **干瘪恶魂离开水会回退**：补水过程必须持续泡在水里。
3. **剪刀取装备要满足三个条件**：不潜行、目标没有骑乘者、目标不是劫掠兽（鞍）。
4. **鞍不再来自那五个结构的箱子**：还在按老路线找鞍的攻略已经过期。
5. **快乐恶魂不吃速度药水**：别浪费。
6. **溅射药水有距离衰减**：团战投掷要更靠近，远程支援效果会明显变弱。
7. **定位条不是默认隐藏的**：想隐蔽行动要主动潜行或戴头盔。

## 八、给不同角色的建议

- **生存玩家**：先把恶魂农场做起来，8 个恶魂之泪换一只坐骑很划算；云层高度（Y 187–196）是免费回血点。
- **服主**：升级前确认 Java 21；决定定位条是否默认关闭；旧世界的鞍箱子会按新战利品表生成，但已生成的容器不会回溯改变。
- **整合包作者**：注意鞍的合成化会削弱"探索奖励"曲线，很多包需要重做战利品表；快乐恶魂可能让飞行类模组的必要性下降。
- **数据包作者**：`waypoint_style` 与 `/waypoint` 是做自定义地图标记的现成工具，不必再靠"隐形盔甲架 + 命名"的土办法。
