## 一句话结论

群骑纷争是 2025 年最后一个 drop，也是这批 drop 里唯一同时改**武器**和**移动**的：矛用 4.5 格的攻击距离和"冲锋可以把人从坐骑上打下来"重写了骑战，鹦鹉螺把水下移动变成可驯养、可穿铠的坐骑，亡灵一侧则成建制地出现了骆驼尸壳、僵尸马、僵尸鹦鹉螺三种可驯服的敌对坐骑。技术侧，1.21.11 是 Java 版**去混淆**的起点，这个意义比任何一件装备都大。

## 二、矛：把"攻击距离"变成一个可以玩的东西

### 2.1 基础规则

官方中文名是**矛**（英文 spear），不是"长矛"。它是分梯队武器，木/金、石/铜、铁、钻石、下界合金共五档。

| 规则 | 数值/说明 |
| --- | --- |
| 攻击距离 | **4.5 格**，其他武器为 **3 格** |
| 最小攻击距离 | 存在下限，**贴脸反而打不到** |
| 多目标 | 一次攻击可以命中多个实体 |
| 命中判定 | 计算命中时把目标碰撞箱**放大 0.125** |
| 合成 | **2 根木棍 + 对应梯队的材料**；钻石升下界合金用锻造台 |
| 附魔 | 专属附魔 **Lunge（突进）I–III** |

### 2.2 刺击（jab）的伤害与攻速

Java 版与基岩版的刺击伤害不同，Java 更低一档：

| 梯队 | Java 刺击伤害（点） | 基岩版刺击伤害（点） | 攻速（Java，次/秒） |
| --- | --- | --- | --- |
| 木 / 金 | 1 | 2 | 木：1.54（0.65 秒） |
| 石 / 铜 | 2 | 3 | 石：1.33（0.75 秒）；铜：1.18（0.85 秒） |
| 铁 | 3 | 4 | — |
| 钻石 | 4 | 5 | — |
| 下界合金 | 5 | 6 | — |

注意这张表的单位是"点"（2 点 = 1 颗心），所以下界合金矛的普通刺击也只有 2.5 颗心——**矛的强度不在刺击，而在冲锋**。

冷却机制也不同：Java 版用的是**攻击冷却的变体，必须蓄满 100% 才能攻击**；基岩版用的是类似末影珍珠的**使用冷却**，而且冷却对背包里所有矛生效。

### 2.3 冲锋（charge）：真正的伤害来源

按住使用键把矛放平进入冲锋姿态。规则是：

- 当使用者与目标的**相对移动速度达到 4.6 格/秒或更快**时，冲锋造成伤害、击退，并把被命中的目标**打下坐骑**；
- 伤害按梯队乘一个倍率：**木/金 0.7×，石/铜 0.82×，铁 0.95×，钻石 1.075×，下界合金 1.2×**；
- 站在地上不动也能造成冲锋伤害（只是低）；
- Java 版**副手也能冲锋**，基岩版不能把矛放副手。

这里有一个实战取向非常明确的设计：**刺击进入冷却时，仍然可以发动冲锋**。两者交替，可以把有效攻击频率翻倍。这是矛区别于剑的核心操作空间——剑是"一次一刀"，矛是"一刀一冲"。

### 2.4 突进（Lunge）

Lunge 是矛的专属附魔，三级：

- **只对刺击（jab）生效**；
- 发动时把玩家**沿视线方向水平推进**；
- **视线完全水平**时推进距离最大（抬头或低头都会缩短）；
- 消耗饱和度与饥饿值，消耗量随附魔等级增加，另外固定消耗 **1 点耐久**；
- **饥饿值低于 6 点时无法使用**。

这条附魔把矛从"长柄武器"变成了"位移工具"：可以用来拉近、拉开、跳崖逃生，代价是饥饿值。在 PVP 里它更像是"短距冲刺"而不是伤害增幅。

## 三、鹦鹉螺：把水下移动做成坐骑

鹦鹉螺是水生中立坐骑，生成在海洋中：

- 被激怒时会对任何生物发动**冲刺攻击**，偶尔捕食河豚；
- **免疫中毒**；
- 用**河豚与河豚桶**驯服和繁殖；驯服之后可以喂任意种类的鱼或鱼桶；
- 幼体有**独立的模型与音效**；
- 用**鞍**骑乘，操作方式类似快乐恶魂（鼠标/摇杆控制），并且有类似骆驼的**冲刺**；
- 骑乘时给骑手 **"鹦鹉螺之息"** 效果：**冻结氧气条**——这是水下长距离移动的关键；
- **上岸会脱水**；
- 被杀死有 **5%** 概率掉落鹦鹉螺壳。

配套的**鹦鹉螺铠**（Nautilus Armor）是分梯队装备：铜、铁、金、钻石四档可在**海洋结构箱子**中找到，**下界合金档由钻石档在锻造台升级**。它**不能合成**——只能找或升级。

## 四、亡灵坐骑：三种新敌对坐骑

这是本版最有意思的设计方向：亡灵不再只是"走路的敌人"，而是**骑着东西来的敌人**，而且这些东西可以抢过来。

### 4.1 骆驼尸壳（Camel Husk）

- 沙漠**夜间**生成的稀有亡灵骆驼变体；
- 生成时**自带两名骑手**：一个持铁矛的尸壳 + 一只焦骸，组成"骆驼尸壳骑手"；
- 尸壳骑手被杀死时有概率掉落**兔子脚**；
- **未骑乘时算敌对生物**，会像敌对生物一样消失；
- **不惧阳光**；
- 行为类似普通骆驼，但**不能繁殖**；
- 可以用**兔子脚**引诱与治疗；掉落腐肉。

### 4.2 僵尸马（Zombie Horse）

- 更换了新纹理；
- 现在在**平原与热带草原夜间自然生成**；
- 生成时由持铁矛的僵尸骑乘，组成"僵尸骑手"；
- 僵尸骑手被杀死时有概率掉落**红蘑菇**；
- 未驯服时算敌对生物，会消失；
- 掉落 **2–3 个腐肉**（此前是 1 个）；
- 可以用**红蘑菇**引诱与治疗；
- **可以装鞍与马铠**；
- **会在阳光下燃烧**，但**穿上马铠可以防止燃烧**。

### 4.3 僵尸鹦鹉螺（Zombie Nautilus）

- 生成在**海洋与滴水石洞穴**；温暖海洋中还有**珊瑚变体**；
- 生成时由持三叉戟的**溺尸**骑乘，组成"僵尸鹦鹉螺骑手"；
- 未驯服时算敌对生物，会消失；
- 行为类似普通鹦鹉螺，但**不能繁殖**；
- 游泳速度比普通鹦鹉螺**快 10%**；
- **上岸不脱水**；
- **会在阳光下燃烧**，但**穿上鹦鹉螺铠可以防止**；
- 掉落腐肉。

### 4.4 通用坐骑改动

驴、骆驼、马、骡、僵尸马在被玩家骑乘时**不再下沉**于水中；但骑手的头一旦没入水面，仍会被甩下坐骑。这条改动让"骑马过河"第一次变得可行，代价是不能潜水。

## 五、下界合金马铠与战利品

**下界合金马铠**提供 **19 点护甲值、3 点护甲韧性、1 点击退抗性**，用**钻石马铠 + 下界合金升级模板**在锻造台升级。它补齐了皮革、铜、铁、金、钻石、下界合金六档马铠。

另外两端战利品变化：

- **矛**：石、铜、铁、钻石矛（含受损与附魔变体）会出现在箱子战利品里；
- **刷怪蛋**：创造模式物品栏按主题重排——主世界分为农场动物、坐骑、宠物、野生动物、水生、杂项、傀儡、村民、亡灵、蜘蛛、怪物、灾厄村民；另有下界与末地分组。

## 六、焦骸（Parched）

焦骸是骷髅的沙漠变体，夜间生成在沙漠：

- **不惧阳光**（与尸壳一致）；
- 射**虚弱之箭**，同时**免疫虚弱**；
- 射速比普通骷髅**更慢**，定位接近沼骸。

这让沙漠夜间多了一种"降攻击力"的远程威胁：被命中后近战伤害下降，正好与"矛需要蓄力"的节奏形成压制。

## 七、技术侧：1.21.11 为什么比看起来重要

### 7.1 去混淆版本

1.21.11 随包发布了一个单独的 **"1.21.11 Unobfuscated"**（启动器里显示为 `1.21.11_unobfuscated`）。官方说明这是**实验性版本**，目的是**为移除 Java 版客户端与服务端的混淆做准备**。

对模组开发生态，这是结构性变化：混淆一旦移除，模组加载器与工具链对 mappings、字节码重写的依赖会显著下降。1.21.11 本身仍是过渡版本，但它标记了方向。

### 7.2 纹理过滤

视频设置新增**纹理过滤**选项，控制纹理在斜视或远距离时的采样方式：

| 模式 | 原理 | 代价 |
| --- | --- | --- |
| RGSS（Rotated Grid Super Sampling） | 着色器实现 | 中等性能开销 |
| 各向异性（Anisotropic） | 硬件实现 | 清晰度更高，**显著增加显存占用**（叠加高 mipmap 级数时尤其明显） |

对低配机器，这是一项需要主动关闭的新默认项；对截图与建筑党，它是画质提升。

## 八、对服主、PVP 与整合包的影响

- **PVP 服**：矛的 4.5 格距离 + 冲锋下坐骑，会让骑战从"撞人"变成"对冲"；Java 与基岩版刺击伤害不同（Java 低一档），跨平台服需要分别说明。
- **生存服**：僵尸马与骆驼尸壳可以引诱驯服，"亡灵坐骑"变成了可获取资源；僵尸马吃红蘑菇、骆驼尸壳吃兔子脚，等于给这两种掉落物加了新用途。
- **水下探索**：鹦鹉螺 + 鹦鹉螺铠 + 鹦鹉螺之息，构成一套完整的水下移动方案；但鹦鹉螺铠不可合成，早期拿不到。
- **模组作者**：去混淆版本是长期利好，但短期仍要按 1.21.11 的 mappings 工作；资源包/数据包格式跳到 **75.0 / 94.1**，注意 `min_format`/`max_format` 写法。
- **整合包**：矛的强度曲线（刺击极弱、冲锋很强）意味着它不适合当"通用武器"塞给新手，更适合作为骑战/冲锋流派的核心。

## 九、常见坑

1. **矛贴脸打不到**：它有一个最小攻击距离，近身要换剑。
2. **Java 版必须蓄满 100% 才能刺击**，连点无效；基岩版则是使用冷却，且对背包里所有矛共用。
3. **冲锋看相对速度**：双方对冲才吃满伤害，站着戳伤害很低。
4. **僵尸鹦鹉螺在阳光下会烧**，必须给它穿鹦鹉螺铠。
5. **鹦鹉螺上岸会脱水**，别把它当陆地坐骑。
6. **骆驼尸壳与僵尸马在未被骑乘时是敌对生物**，会像怪物一样消失，想留下必须先驯服。
7. **官方中文名是"矛"**，搜"长矛"可能找不到对应条目。
8. **1.21.11 之后版本号变成 26.x**，查资料时别把 26.1 当成"1.26.1"。
