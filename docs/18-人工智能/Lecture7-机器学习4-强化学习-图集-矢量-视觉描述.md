score(a) = Q(a) + η * (π(a|St;θ) / (1 + N(a)))

其中：
- Q(a) 表示动作 a 的奖励值

- η 是一个正数参数
- N(a) 表示动作 a 的次数
- θ 是模型参数

这个公式用于计算动作 a 的分数，分数由奖励值、动作的概率和动作的次数决定。
