## Lecture03-PropBasic-图集 第 35 页
这是一张关于命题逻辑公式真值表的课程讲义插图。图中详细列出了命题逻辑公式在不同真值赋值函数下的真值情况。具体包括：

1. 如果A是命题变量p，则σ(A) = σ(p)。2. 如果A具有形式(¬B)，则σ(A) = 1当且仅当σ(B) = 0。3. 如果A具有形式(B ∧ C)，则σ(A) = 1当且仅当σ(B) = 1且σ(C) = 1。4. 如果A具有形式(B ∨ C)，则σ(A) = 0当且仅当σ(B) = 0且σ(C) = 0。5. 如果A具有形式(B → C)，则σ(A) = 0当且仅当σ(B) = 1且σ(C) = 0。6. 如果A具有形式(B ↔ C)，则σ(A) = 1当且仅当σ(B) = σ(C)。图中还强调了σ(A)的值要么是1要么是0，确定了σ(A)何时等于1也就确定了它何时等于0，反之亦然。这张图主要说明了命题逻辑公式在不同真值赋值函数下的真值情况，以及如何通过真值表确定公式在不同条件下的真值。
