离散数学与离散数学基础课程
什么是离散数学？
离散数学(Discrete mathematics)是以可枚举(enumerable)的数量或形状作为研究对象的数学分支
可枚举指对象与对象间有清晰明确界限，可一一罗列
离散数学研究与自然数集或其子集有一一对应关系的对象集合
现在的计算机只能处理可枚举的信息
任何由计算机处理的信息都必须编码为可枚举的二进制数据
离散数学在计算机科学有广泛应用
什么是离散数学基础课程？
离散数学基础是计算机专业学生的核心理论基础课程
提供逻辑(logic)、集合(set)、算法(algorithm)、图论(graph)和代数(algebra)等数学语言描述可枚举的数学对象
使得人们在利用计算机求解问题时可建立合适的离散数学模型并对其进行分析

课程教学理念-强化与计算机问题求解间的联系
计算机问题求解时的五种思考方向（计算机专业意识，或计算思维的具体体现）
离散化是在求解问题时应将复杂问题分解为一系列可枚举的简单问题
模块化是指这种分解应尽量得到一个个可独立求解的问题，或称为模块
层次化是指这些模块可形成不同的抽象层次
系统化是指分解应遵循某种统一的标准，保证可不遗漏地求解原来的问题
公理化是指在分解得到的一堆问题中应尽量发现其中最基本的问题，以便通过组合最基本问题的解来解决其他问题

课程教学理念-强化与计算机问题求解间的联系
|  | 程序设计课程 | 离散数学课程 |
|---|---|---|
| 离散化 | 编程求解复杂问题时的功能自顶向下分解 | 构造非形式化证明或形式化论证的分析思路（或称为反向推理） |
| 模块化 | 程序中引入函数、类等模块 | 形式化论证中使用基本推理规则及派生规则、非形式化证明中引用已有引理、非形式化证明的分情况证明、逻辑等值演算使用已有逻辑等值式、集合等式证明使用已有集合等式、组合计数的加法原理的分类处理 |
| 层次化 | 函数、类等模块的接口使得模块的使用者和实现者分离，从而模块形成不同的抽象层次 | 通过分析在不同层次把握证明或论证的构造思路、组合计数加法原理和乘法原理分层综合运用、一般代数和群格等具体代数形成不同抽象层次 |
| 系统化 | 系统化地考虑正常情况、异常情况和边界情况以保证分支语句或循环语句能处理各种情况 | 非形式化证明的分情况证明所分情况要不遗漏不重复各种情况、组合计数加法原理的分类处理要不遗漏不重复各种类别 |
| 公理化 | 找出最基本的函数和最基本的类提高程序的可重用性 | 逻辑等值演算的基本等值式、逻辑推理系统的基本推理规则、集合恒等式的基本等式、组合计数问题的基本计数问题、群格等代数系统的基本性质 |
