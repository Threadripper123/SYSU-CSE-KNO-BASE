1. **分支指令地址**：表示当前指令的地址。2. **分支历史记录表 BHT**：包含三个列：分支指令地址、预测位、转移目标地址。3. **查找**：当分支指令地址与预测位不相等时，表示未命中。4. **命中时**：根据预测位选择“转移取”还是“顺序取”。5. **未命中时**：加入新项，并填入指令地址和转移目标地址、初始化预测位。6. **转移取**：根据预测位选择“转移取”。7. **顺序取**：根据预测位选择“顺序取”。这张图说明了分支历史记录表如何根据预测位选择转移指令还是顺序指令，以及如何在未命中时更新预测位。

## 第4章第4讲-流水线处理器-图集 第 31 页
这是一张示意图，描述了一个两级的（2,2）预测器的结构。图中显示了分支地址（Branch address）为4的情况。预测器由四个2位的分支预测器（2-bits per branch predictor）组成，每个预测器对应一个分支。预测器的输出通过一个预测（Prediction）箭头连接到一个2位全局分支历史（2-bit global branch history）。图说明了预测器如何根据全局分支历史和当前分支地址来预测分支的取值。

## 第4章第4讲-流水线处理器-图集 第 32 页
这是一张电路图，展示了单周期和流水线两种执行方式的比较。图中显示了两个周期（Cycle 1 和 Cycle 2）的时序关系，以及在每个周期中执行的指令（Load 和 Store）。关键元件或元素包括：
- Clk：时钟信号
- Load：加载指令
- Store：存储指令
- Ifetch：指令预取
- Reg：寄存器
- Exec：执行
- Mem：内存访问
- Wr：写回

图上出现的文字标签包括：
- Single Cycle Implementation
- Pipeline Implementation
- Load
- Store
- R-type

这张图说明了单周期执行方式和流水线执行方式在执行指令时的差异，单周期执行方式在每个周期内只能执行一个指令，而流水线执行方式通过多级流水线结构，可以在一个周期内执行多个指令。
