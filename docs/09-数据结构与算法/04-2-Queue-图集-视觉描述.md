```cpp
int Poisson(double mean);
```

函数的注释说明了它返回一个随机整数，反映一个参数为 `mean` 的泊松分布。函数的实现部分如下：

```cpp
{
    double u = (double)rand() / RAND_MAX;
    double v = (double)rand() / RAND_MAX;
    int k = 0;
    while (u > v) {
        k++;
        v *= u;
    }
    return k;
}
```

这段代码使用了两个随机数生成器 `rand()` 来生成两个独立的随机数 `u` 和 `v`，然后通过一个循环来计算泊松分布的概率。循环的条件是 `u > v`，直到 `u` 小于等于 `v`。循环的次数 `k` 就是返回的随机整数。
