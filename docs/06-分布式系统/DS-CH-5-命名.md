名称
Ø
本质：
用名字标识分布式系统中的实体对象，由字符组成的字符串。
实体可以是分布式系统中的任何事物，包括：主机、打印机、磁
盘和文件等硬件资源，还包括：用户、邮箱、消息等抽象资源。
Ø
访问点（
access point
）
对实体可进行一系列的操作，需要访问实体，因此需要一个
访问点。访问点是一类特殊的实体，访问点的名称成为地址。实
体的访问点的地址即为该实体的地址。
一个独立于实体地址的名称通常是比较合理的，而且更为灵活，
这样的名称是与位置无关
