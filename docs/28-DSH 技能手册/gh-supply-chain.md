# 供应链与库存管理

## 适用场景

- 库存积压或缺货频发，需要定补货规则。
- 需求预测与安全库存测算。
- 供应商比价、交期与风险评估。
- 不适用：纯运筹求解细节（用 `gh-operations-research`）；财务成本核算（用 `gh-accounting-tax`）。

## 前置条件

- 数据：至少 12 个月历史出库记录（含日期、SKU、数量）、采购提前期、当前库存与在途。
- 明确服务水平目标（如 95% 不缺货概率），这直接决定安全库存水平。
- 明确持有成本率（资金占用 + 仓储 + 损耗，通常年化 15%–30%）。

## 步骤

1. **需求分析**：先分类——稳定需求、趋势性、季节性、间歇性（大量零值）。**不同类别用不同预测方法**，一套方法套全部必然不准。
2. **预测方法**：
   - 稳定/趋势：移动平均、指数平滑（Holt）。
   - 季节性：Holt-Winters。
   - 间歇性：Croston 法。
   - 用 MAPE/偏差（bias）评估，注意间歇性需求 MAPE 会失真，改用 MAE 或 pinball loss。
3. **安全库存**：`SS = Z × σ_d × √L`（`Z` 由服务水平定，`σ_d` 为提前期内需求标准差，`L` 为提前期）。提前期本身有波动时要叠加 `σ_L` 项。
4. **补货策略**：
   - `(s, S)`：库存降到 s 补到 S，适合间歇需求。
   - `(R, Q)`：定期检查补固定量，适合供应商有最小起订量。
   - EOQ 只适用于需求稳定且无数量折扣的场景，别硬套。
5. **ABC 分类**：按年消耗金额排序，A 类（前 80% 金额）精细管理、高频盘点；C 类简化管理。
6. **供应商评估**：价格、交期稳定性、质量合格率、最小起订量、账期。加权打分而不是只看价格。
7. **风险**：单一供应商、长提前期、地缘与汇率风险；关键物料准备替代源。

## 常见坑

- 用全年平均需求算安全库存，忽略季节波动，旺季必然缺货。
- 服务水平从 95% 提到 99% 安全库存可能翻倍，成本收益要算清再定。
- 忽略提前期波动，只算需求波动。
- 把滞销品和畅销品用同一补货规则。
- 预测准确率用 MAPE 评估间歇性需求，得到几百 % 的无意义数值。
- 只看采购单价不看总拥有成本（物流、库存、质量损失）。
- 促销活动不做单独预测，活动后大量退货或积压。

## 验证

- 预测在留出的测试期上评估，报告 bias 而不只是误差。
- 安全库存与服务水平的对应关系明确写出。
- 补货规则用历史数据回放，测算缺货率与平均库存。
- 供应商评分表可追溯到原始数据。
