# PowerPoint演示制作与审阅

仅在任务匹配本技能时应用。当前用户要求、系统规则与实际工具权限优先。此为GitHub上游技能的本机兼容适配版，默认中文输出。不要假定上游列出的工具、包、API密钥或Linux命令已可用；先检查环境，优先当前软件已有工具。不要自动调用收费服务、上传本地私密资料或运行上游安装命令。

创建、读取、修改PPT与模板。先明确受众、目的和时长，读取模板及素材，每页围绕一个可说明的结论。使用已有演示工具或python-pptx；如用PptxGenJS，先检查模块是否存在，明确页面尺寸、坐标与颜色格式，避免复用会被修改的选项对象。保持图表可编辑、字体层级一致、图像比例正确，数据注明来源。先完成增加删除重排，再填文字；修改run以保留格式。检查包结构、页数与备注，渲染后逐页核对溢出、重叠与对比度。

上游来源：https://github.com/anthropics/skills/tree/2c5958ecac7cee2b583967a2c4981d0f4a75c579/skills/pptx

详细参考与脚本见本技能目录的 UPSTREAM.md、references/、scripts/ 或其他附属文件；只在需要时读取。以上兼容约定替代上游关于预装环境、强制服务和默认数量的假设。
