# 商业分析与行业研究

## 适用场景

- 估算某产品/赛道的市场规模与增速（TAM/SAM/SOM）。
- 分析竞争格局、对手打法、进入壁垒。
- 判断一个商业想法是否成立：谁付费、为什么付、能否规模化。
- 不适用：纯财务测算（用 `gh-financial-modeling`）；战略框架套用（用 `gh-strategy-frameworks`）。

## 前置条件

- 先确认分析目的：是投资判断、内部立项，还是对外研究？目的不同，口径不同。
- 数据来源分级：一手（访谈、内部数据）> 官方统计/年报 > 券商与咨询报告 > 媒体报道。**每一条关键数字必须标注来源与年份**。
- 不编造数据。拿不到就写"未获取"，并说明这会让哪个结论不确定。

## 步骤

1. **定义边界**：产品是什么、卖给谁、在哪个地域、算哪一年。边界不清的规模测算没有意义。
2. **市场规模自上而下**：行业总量 → 细分占比 → 可服务市场。用两个独立口径交叉验证（如人口×渗透率×客单价 vs 行业报告总量×细分比例），两法结果差距超过 3 倍要解释原因。
3. **自下而上校验**：从已知的头部玩家收入反推其份额，检验自上而下的总量是否荒谬。
4. **竞争分析**：列出主要玩家、定位、价格带、渠道、核心能力。判断集中度（CR3/CR5）与进入壁垒（牌照、资本、网络效应、转换成本）。
5. **需求验证**：区分"想要"和"付费"。看已付费行为（复购率、客单价、留存）而不是问卷意向。
6. **单位经济模型**：LTV / CAC / 回收周期。LTV/CAC < 1 的模式不成立；回收周期超过现金流承受期要标红。
7. **结论写法**：给"成立/有条件成立/不成立"，并列出 3 个最可能推翻结论的假设。

## 常见坑

- TAM 用"全球×全行业"凑大数字，得出人人都能做千亿市场的荒谬结论。必须收敛到 SAM/SOM。
- 把行业报告的预测增速当事实，报告本身常由卖方出具存在系统性乐观偏差。
- 用问卷"你愿不愿意付费"验证需求，得到的都是虚高答案。
- 忽略渠道成本：账面毛利 60% 但渠道抽成后不足 15%。
- 混淆存量与增量市场：存量市场里增长只能靠抢份额，打法完全不同。
- 结论给了一堆分析却没有明确判断。

## 验证

- 每个关键数据附来源 + 年份 + 口径。
- 规模测算至少两种方法交叉核对，差异有解释。
- 结论明确，并列出可被证伪的假设与验证方式。
