# 阅读报告与文献综述

仅在任务匹配本技能时应用。当前用户要求、系统规则与实际工具权限优先。此为GitHub上游技能的本机兼容适配版，默认中文输出。不要假定上游列出的工具、包、API密钥或Linux命令已可用；先检查环境，优先当前软件已有工具。不要自动调用收费服务、上传本地私密资料或运行上游安装命令。

为书籍、文章、论文与多文献材料撰写阅读报告或综述。先实际读取材料，记录题名作者版本、页码或章节与引用位置；未取得全文时明确范围。普通阅读报告采用作品概况、核心论点或情节、结构与写法、证据分析、批判评价、联系与反思、结论及参考资料，避免套用医学综述表格。学术综述先定义问题与纳排标准，再记录检索式、时间和数据库，去重筛选、提取方法结论及局限，用主题比较和证据矩阵综合，不逐篇堆摘要。引文逐条核验，区分作者观点与个人评价，不编造页码引文或宣称检索穷尽。
