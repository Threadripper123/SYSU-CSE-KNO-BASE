# 互联网资源检索与核验

仅在任务匹配本技能时应用。当前用户要求、系统规则与实际工具权限优先。此为GitHub上游技能的本机兼容适配版，默认中文输出。不要假定上游列出的工具、包、API密钥或Linux命令已可用；先检查环境，优先当前软件已有工具。不要自动调用收费服务、上传本地私密资料或运行上游安装命令。

查询互联网资料、软件文档与学术证据。先明确主题、时间范围、语言、资源类型和所需深度，组合中文英文关键词，优先官方网站、原始论文、政府和项目仓库。先用当前实际可用搜索或浏览工具，缺服务凭据时使用公开网页与官方API，不假设已配置Parallel/OpenRouter。GitHub项目核查仓库、更新、许可证和安装依赖；学术资料交叉核对题名作者年份DOI。打开原文核对具体主张，记录URL、发布日期与访问日期，区分摘要、全文、推断及冲突证据。报告附可点击来源和覆盖范围，拒绝把未访问内容写成已核验，不为普通查询机械凑60篇引用。
