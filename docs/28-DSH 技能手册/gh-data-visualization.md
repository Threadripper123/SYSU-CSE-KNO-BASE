# 数据可视化与图表设计

## 适用场景

- 把分析结果做成图给决策者看。
- 探索数据分布、趋势、相关性时选图。
- 做经营看板、周报图表、汇报插图。
- 不适用：纯数值结论（不需要图）；文档排版（用 Office 类技能）。

## 前置条件

- 本机 matplotlib **未安装**：`pip install matplotlib`；或直接用 `gh-office-xlsx-extra` 在 Excel 里出图。
- 中文字体：Windows 用 `Microsoft YaHei`，需显式设置 `plt.rcParams['font.sans-serif']`，否则中文变方框。
- 先想清楚"这张图要让读者得出什么结论"，再选类型。

## 步骤

1. **按问题选图**：
   - 比较类别 → 条形图（横向更适合长标签）。
   - 时间趋势 → 折线图（不要用柱状图表示长序列）。
   - 分布 → 直方图/箱线图/小提琴图。
   - 构成 → 堆叠条形（饼图超过 5 类就不要用）。
   - 关系 → 散点图（可加趋势线与相关系数）。
   - 多维对比 → 小倍数图（facet grid）优于在一张图堆多条线。
2. **减少无效墨迹**：去掉多余网格线、边框、图例（颜色已能区分时），坐标轴从 0 开始或明确截断标记。
3. **色彩**：类别用定性色板（≤8 类），数值用连续色阶；色盲友好（避开红绿对立，用蓝橙）。重点项用强调色，其余灰化。
4. **标注直接写在图上**：关键拐点、最大值、事件点直接标注，减少读者对照图例的时间。
5. **标题写结论**：标题写"Q3 收入同比 +23%，主要来自华东区"而不是"Q3 收入图"。
6. **一致性**：同一份报告里同类图表用同一色板、同一轴范围、同一单位。
7. 出图参数：`dpi=150` 以上、`bbox_inches='tight'`，保存 PNG/SVG 而非截图。

## 常见坑

- Y 轴不从 0 开始且未标注，制造夸大的变化幅度。
- 双 Y 轴随意缩放两条线，强行制造"相关"。
- 饼图类别过多或占比相近，完全无法读。
- 用颜色区分超过 8 类，读者无法分辨。
- 中文乱码（未设字体）。
- 图例与数据颜色不对应，或图例遮挡数据。
- 只给图不给数据表，精确值无法获取。

## 验证

- 图能在一句话内说清结论。
- 坐标轴、单位、时间范围标注完整。
- 中文正常显示。
- 导出文件在目标文档中插入后清晰可读。
