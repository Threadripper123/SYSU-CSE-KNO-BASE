# PDF阅读提取与处理

仅在任务匹配本技能时应用。当前用户要求、系统规则与实际工具权限优先。此为GitHub上游技能的本机兼容适配版，默认中文输出。不要假定上游列出的工具、包、API密钥或Linux命令已可用；先检查环境，优先当前软件已有工具。不要自动调用收费服务、上传本地私密资料或运行上游安装命令。

阅读提取PDF文字表格、拆分合并、旋转与表单处理。先检查页数、是否有文本层、加密或扫描页；按实际工具选择pypdf、pdfplumber或已有PDF引擎，扫描页在OCR可用时识别。保留页码定位和表格单位，复杂多栏需视觉核对阅读顺序。输出为新文件，核对页面数量、方向、文本和表单字段；不要把普通文本提取说成OCR，不声称解除未知密码。Office转PDF使用当前可用转换工具并检查布局。

上游来源：https://github.com/anthropics/skills/tree/2c5958ecac7cee2b583967a2c4981d0f4a75c579/skills/pdf

详细参考与脚本见本技能目录的 UPSTREAM.md、references/、scripts/ 或其他附属文件；只在需要时读取。以上兼容约定替代上游关于预装环境、强制服务和默认数量的假设。
