# 会计与税务实务

## 适用场景

- 编制利润表、资产负债表、现金流量表。
- 收入确认、成本归集、费用分摊的业务判断。
- 常见税种测算与税负分析（增值税、企业所得税等）。
- 不适用：估值与投资测算（用 `gh-financial-modeling`）。

## 前置条件

- **本技能提供通用分析框架，具体税务处理以现行法规与主管税务机关口径为准**；重大事项须由注册会计师/税务师复核。
- 明确会计期间、记账本位币、企业性质（一般纳税人/小规模）与适用税率。
- 拿到完整凭证与合同，判断依据是业务实质而非发票名称。

## 步骤

1. **确认基础**：会计期间、权责发生制还是收付实现制（内部管理账可用后者，对外报表必须前者）。
2. **收入确认**：控制权是否转移（发货、验收、签收）、是否含退货权、是否存在代销或多要素合同需分摊。**开票不等于收入确认**。
3. **成本归集**：直接材料、直接人工、制造费用；分摊方法（工时、机时、产量）一旦确定应保持一致，变更需披露。
4. **费用划分**：资本化 vs 费用化（研发支出、借款费用）；折旧摊销政策与年限。
5. **三表编制**：利润表按收入−成本−费用−税；资产负债表配平（资产=负债+所有者权益）；现金流量表分经营/投资/筹资三类。**间接法编制经营现金流时从净利润起调，加减非现金项与营运资本变动**。
6. **税负测算**：
   - 增值税：一般纳税人 `应纳税额 = 销项 − 进项`，注意进项抵扣条件与不得抵扣情形。
   - 企业所得税：`应纳税所得额 = 利润总额 ± 纳税调整`，注意业务招待费、广告费、研发加计的限额与优惠。
   - 附加税费按增值税额计征。
7. **勾稽检查**：利润表净利润 = 资产负债表未分配利润变动（扣除分配）；现金流量表期末现金 = 资产负债表现金科目。
8. 输出：科目余额表、三表、关键判断依据说明、税负测算表。

## 常见坑

- 把开票时点当作收入确认时点，导致跨期收入错配。
- 增值税进项税违规抵扣（用于集体福利、免税项目的进项不得抵扣）。
- 研发费用加计扣除的归集口径不符要求（需辅助账、项目立项）。
- 折旧年限随意变更调节利润。
- 三表不勾稽，净利润与未分配利润变动对不上。
- 混淆含税价与不含税价，收入虚增 13%。
- 忽略小规模纳税人优惠与小微型企业优惠的适用条件。

## 验证

- 三表勾稽关系逐项核对通过。
- 收入确认、成本分摊的每项判断都有合同或业务证据支撑。
- 税负测算列出适用税率与依据，敏感项标注。
- 明确声明需专业复核的事项。
