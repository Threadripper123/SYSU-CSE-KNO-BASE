# 投资研究与组合分析

## 适用场景

- 研究单个标的：业务质量、财务健康、估值是否合理。
- 构建或检视组合：集中度、相关性、风险预算。
- 绩效归因：收益来自选股、择时还是行业配置。
- 不适用：财务模型搭建细节（用 `gh-financial-modeling`）；回测工程（用 `gh-market-data-quant`）。

## 前置条件

- **本技能是分析框架，不构成投资建议**。任何结论须标注数据截止日期与来源。
- 数据：至少 5 年财报、当前估值倍数、同业对比数据。
- 明确投资期限与约束（流动性需求、回撤容忍度、单一标的仓位上限）。

## 步骤

1. **先定投资逻辑一句话**：赚的是什么钱——盈利增长、估值修复、周期反转、还是股息？逻辑不清的不进入下一步。
2. **业务质量**：ROE/ROIC 的持续性（拆解为利润率×周转率×杠杆，看哪项在起作用）、护城河来源、行业地位变化。
3. **财务健康**：
   - 现金流质量：经营现金流 / 净利润长期应接近或大于 1。
   - 杠杆：有息负债/EBITDA、利息保障倍数。
   - 造假信号：应收增速远超收入、存货异常、经营现金流长期低于净利润、频繁变更会计政策。
4. **估值**：当前倍数 vs 自身历史分位 vs 同业分位。判断"便宜"要区分"周期底部盈利低导致倍数虚高"和"真的被低估"。
5. **反向论证**：主动写空头逻辑——最可能让这笔投资亏钱的三个原因，以及各自的观测指标。
6. **组合层面**：
   - 集中度：单一标的、单一行业权重上限。
   - 相关性：持仓间相关系数矩阵，避免表面分散实则同涨同跌。
   - 风险预算：按波动率贡献而非资金占比分配。
7. **绩效归因**：`组合收益 − 基准收益` 拆成行业配置贡献 + 个股选择贡献 + 交互项。
8. 输出：结论、关键假设、观测指标、退出条件（什么情况下卖出）。

## 常见坑

- 只找支持自己观点的证据（确认偏误），不做反向论证。
- 用后视镜数据回测出漂亮曲线，忽略幸存者偏差与交易成本。
- 把低估值等同于低风险：周期股在盈利高点时 P/E 最低，恰是最危险的时候。
- 组合看似持有 20 只股票但同属一个产业链，实际是单一押注。
- 忽略流动性：小市值标的建仓容易退出难。
- 没有退出纪律，盈利了不知道何时卖、亏损了死扛。

## 验证

- 每条结论有数据支撑并标注截止日期。
- 明确写出空头逻辑与对应的观测指标。
- 组合层面给出集中度与相关性数字。
- 给出可执行的退出条件。
