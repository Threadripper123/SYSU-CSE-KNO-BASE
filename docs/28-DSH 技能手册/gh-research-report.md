# 行业研究与商业报告撰写

## 适用场景

- 写行业研究、市场分析、尽职调查材料。
- 把零散资料整合成有结论的正式报告。
- 需要引用来源、数据可核验的长文档。
- 不适用：日常汇报（用 `gh-biz-writing`）；学术论文（用 `gh-experiment-report`）。

## 前置条件

- 先定报告目的与读者：投资决策、内部立项、还是对外发布？口径完全不同。
- 资料收集完成度检查：至少覆盖行业规模、竞争格局、产业链、驱动与制约因素、政策环境五个维度。
- **每个关键数据必须有来源与年份**；拿不到就标注"未获取"，不臆造。

## 步骤

1. **先写结论与目录，再填空**：先确定 3–5 个核心判断，再为每个判断组织证据章节。反过来写必然变成资料堆砌。
2. **报告骨架**：
   - 摘要（核心结论 + 关键数据，独立可读）
   - 行业概况（规模、增速、发展阶段）
   - 产业链与商业模式（谁赚钱、怎么赚）
   - 竞争格局（集中度、主要玩家、壁垒）
   - 驱动因素与制约因素
   - 政策与监管环境
   - 趋势判断与风险
   - 附录（数据表、来源清单、方法论）
3. **数据交叉验证**：同一指标用两个独立来源比对，差异大时说明原因（口径不同/年份不同/统计范围不同）。
4. **区分事实与判断**：事实标来源，判断标明"这是我们的推断"并给出推理链。
5. **图表服务于论点**：每张图下面写一句"这张图说明什么"，不能只放图不解读。
6. **引用规范**：正文标注来源，文末列完整来源清单（机构、报告名、年份、链接）。
7. **写作要求**：少用形容词，多用数字；段落一主题；每章末尾小结一句。

## 常见坑

- 资料堆砌成"综述"，没有自己的判断。
- 数据无来源或来源是二手媒体转述，无法核验。
- 不同章节的数据口径不一致（一个用出货量一个用零售量）。
- 只写机会不写风险，结论过度乐观。
- 摘要写成引言，读完了还不知道结论。
- 图表没有解读，读者自己猜。
- 引用过期数据（用三年前的规模说当前市场）。

## 验证

- 每个核心结论都有支撑数据与来源。
- 数据口径全文一致。
- 摘要可独立成篇。
- 来源清单完整，关键数据可回溯。
- 明确标注哪些是事实、哪些是推断。
