# 行情数据与量化回测

## 适用场景

- 拉取并清洗股票/期货/基金历史行情，做统计研究。
- 验证一个交易规则的历史表现。
- 构建因子并做分层回测、IC 分析。
- 不适用：基本面研究（用 `gh-investment-analysis`）；实盘下单系统对接。

## 前置条件

- 数据源（本机均未安装，按需装）：A 股用 `pip install akshare`（免费）或 `tushare`（需 token）；海外用 `pip install yfinance`。
- 网络受限时优先用本地已有数据文件，不要假设外网接口稳定可用。
- 已装：pandas 3.0.3、numpy 2.2.6、scipy 1.15.3、scikit-learn 1.9.0。

## 步骤

1. **数据清洗先行**：复权处理（前复权用于回测、后复权用于展示）、停牌与退市处理、缺失值、重复日期、时区统一。**未复权的价格做回测必然出现虚假跳空收益**。
2. **防未来函数**：任何时点 t 的决策只能用 t 及之前的数据。财务数据要考虑公告滞后期（用报告期会引入未来信息）。
3. **样本内外划分**：按时间顺序切分（不能随机打乱），留出至少 20% 做样本外检验。
4. **回测引擎要点**：
   - 交易成本：佣金 + 印花税 + 滑点，缺一不可；高频策略成本常吃掉全部超额收益。
   - 成交假设：信号当天收盘价成交是乐观假设，改用次日开盘更接近现实。
   - 涨跌停与停牌无法成交要显式建模。
5. **绩效指标**：年化收益、年化波动、Sharpe、最大回撤、Calmar、胜率、盈亏比、换手率。**必须同时报最大回撤与回撤回补时间**。
6. **稳健性检验**：参数敏感性（邻域参数表现是否稳定）、分年度表现、不同市场状态（牛/熊/震荡）下表现、剔除最优 5% 交易后是否仍有效。
7. **防过拟合**：试验次数越多，最好结果越可能是噪声。构造随机策略作对照基准，比较其最优表现分布。
8. 输出：策略逻辑、数据区间、成本假设、完整指标表、失效条件。

## 常见坑

- 用未来数据（财务数据按报告期而非公告日对齐）导致回测收益虚高，这是最常见也最致命的错误。
- 忽略交易成本与滑点，日频策略换手率高时差异可达年化 10% 以上。
- 参数在样本内调到最优，样本外直接失效。
- 幸存者偏差：只用当前还在上市的股票回测，退市的亏损样本被剔除。
- 用小样本（不足 2 年或交易次数 < 30）下结论。
- 只报收益不报回撤。
- pandas 3.0 的 `fillna(method=)` 已废弃，用 `ffill()`/`bfill()`。

## 验证

- 复权与停牌处理有明确代码路径与检查输出。
- 样本外结果单独报告，与样本内对比。
- 加入成本前后收益对比明确列出。
- 参数邻域敏感性表给出（不能只有一个最优参数点）。
