# 经济学分析与政策评估

## 适用场景

- 分析价格变化对需求/供给的影响（弹性测算）。
- 评估某项政策或活动的事后效果（准实验方法）。
- 解读宏观数据（CPI、PMI、社融、就业）与周期位置。
- 不适用：企业财务测算（用 `gh-financial-modeling`）；市场规模测算（用 `gh-business-analysis`）。

## 前置条件

- 明确分析层次：微观（个体/企业/市场）还是宏观（总量/政策）。
- 数据：面板数据或时序数据；政策评估需要处理组与对照组。
- 工具：pandas 3.0.3、scipy 1.15.3、scikit-learn 1.9.0 已装；回归/面板模型需 `pip install statsmodels`（本机未装）。

## 步骤

1. **先写清因果链条**：谁受影响、通过什么机制、预期方向和量级。避免"数据显示相关所以有因果"。
2. **判断能否做因果推断**：
   - 有随机分配 → 可直接比较均值。
   - 有政策断点（如按某阈值划线）→ 断点回归 RDD。
   - 有处理组/对照组且政策前后都有数据 → 双重差分 DID（**必须先检验平行趋势**）。
   - 只能做匹配 → 倾向得分匹配 PSM，并说明残留混淆。
3. **弹性测算**：`需求价格弹性 = (%ΔQ)/(%ΔP)`，用回归取对数形式估计系数；区分短期弹性与长期弹性。
4. **宏观数据解读**：区分同比与环比（`环比` 受季节影响，需季调）、名义与实际（扣除价格因素）、存量与流量。
5. **识别陷阱**：
   - 相关不等于因果；遗漏变量导致伪相关。
   - 选择偏差（只观测到存活样本）。
   - 反向因果（增长导致政策，而非政策导致增长）。
6. **量化不确定性**：给置信区间而非点估计；说明识别假设与违反后果。
7. 输出：机制说明、识别策略、估计结果（含置信区间）、稳健性检验、政策含义。

## 常见坑

- 直接用前后对比当作政策效果，忽略同期其他变化（用 DID 剥离共同趋势）。
- DID 不做平行趋势检验，处理组与对照组本就不同轨。
- 同比与环比混用，把季节性波动说成趋势。
- 用名义值分析购买力变化，未扣除通胀。
- 样本量不足或处理组太少，估计不稳定。
- 只报显著结果，不报不显著的结果（发表偏倚）。
- 把统计显著等同于经济意义上重要。

## 验证

- 识别策略与假设明确写出，附平行趋势/断点有效性检验。
- 结果含置信区间与稳健性检验（换样本期、换控制变量）。
- 区分统计显著与经济显著（报告效应量）。
- 宏观数据明确标注同比/环比、名义/实际口径。
