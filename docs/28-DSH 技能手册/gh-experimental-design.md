# 实验设计与可复现记录

仅在任务匹配本技能时应用。当前用户要求、系统规则与实际工具权限优先。此为GitHub上游技能的本机兼容适配版，默认中文输出。不要假定上游列出的工具、包、API密钥或Linux命令已可用；先检查环境，优先当前软件已有工具。不要自动调用收费服务、上传本地私密资料或运行上游安装命令。

用于实验方案、对照、随机化、重复与因素设计。明确可检验问题、假设、自变量因变量、实验单位、测量方法和混杂因素。按目标选择完全随机、区组、因子、重复测量或其他设计，区分技术重复与独立样本，记录随机种子与软件版本。给出材料、仪器、操作顺序、参数、记录表和分析计划。使用上游DOE脚本前检查所需包，不能把实验计划写成已完成实验。记录失败、偏离与不确定性，不凭空补样本数、伦理批准或结果。

上游来源：https://github.com/K-Dense-AI/claude-scientific-skills/tree/a25cf9ec00e2745d03f8704acf6f6919694ccd9a/skills/experimental-design

详细参考与脚本见本技能目录的 UPSTREAM.md、references/、scripts/ 或其他附属文件；只在需要时读取。以上兼容约定替代上游关于预装环境、强制服务和默认数量的假设。
