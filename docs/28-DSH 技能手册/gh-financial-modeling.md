# 财务建模与估值

## 适用场景

- 为一家公司/项目做 3–5 年财务预测与估值。
- 判断一笔投资的回报率与回收期。
- 做并购、融资、内部立项的财务测算。
- 不适用：市场与竞争判断（用 `gh-business-analysis`）；风险度量（用 `gh-risk-management`）。

## 前置条件

- **本技能输出的是分析工具结果，不构成投资建议**；涉及真实资金决策须由持牌专业人士复核。
- 数据：至少三年历史报表（收入、成本、费用、资本开支、营运资本、有息负债）。
- 工具：Excel/openpyxl 或 Python（pandas 3.0.3 + numpy 2.2.6 已装）。

## 步骤

1. **先搭结构再填数**：假设页（Assumptions）→ 三表（利润表、资产负债表、现金流量表）→ 估值页 → 敏感性页。所有硬编码数字只出现在假设页。
2. **三表联动**：净利润进留存收益、资本开支进固定资产与现金流、营运资本变动进现金流。**做完必须检查资产负债表配平（资产 = 负债 + 权益），差额应为 0**。
3. **收入预测拆分驱动因子**：量×价、客户数×ARPU、门店数×单店收入。不做单一增长率的直线外推。
4. **DCF**：
   - 自由现金流 `FCFF = EBIT×(1-t) + 折旧摊销 − 资本开支 − 营运资本增加`。
   - `WACC = E/V×Re + D/V×Rd×(1-t)`，`Re` 用 CAPM。
   - 终值用永续增长 `TV = FCF_n×(1+g)/(WACC−g)`，并检查 `g < WACC` 且 `g` 不高于长期名义 GDP 增速。
   - 折现到估值日，注意现金流发生在期中还是期末的口径一致。
5. **相对估值**：选可比公司，用 EV/EBITDA、P/E、P/S，说明为什么选这些倍数、可比公司为何可比；对倍数做中位数与分位数处理，剔除异常值。
6. **敏感性分析**：至少对 WACC ±2%、永续增长率 ±1%、收入增速 ±20% 做二维表，给出估值区间而非单点。
7. **情景分析**：悲观/基准/乐观三档，每档写明触发条件与关键假设差异。
8. 交付：模型文件 + 假设清单 + 估值区间 + 主要风险。

## 常见坑

- 三表不配平却继续往下算，整个模型报废。每改一次假设都重查配平。
- 终值占企业价值 80% 以上却不做敏感性，等于用一个假设决定全部结论。
- WACC 用错口径：股权成本用无风险利率、债务成本忘记税盾。
- 折旧与资本开支混为一谈；快速增长期 CapEx 远大于折旧，直接等号会低估现金消耗。
- 营运资本变动方向搞反（收入增长通常占用现金，是现金流的减项）。
- 用 P/E 比较不同资本结构的公司，应改用 EV/EBITDA。
- 单位混乱：万元与元混用导致差 4 个数量级。

## 验证

- 资产负债表配平差额 = 0（打印确认）。
- 现金流表期末现金 = 资产负债表现金科目。
- 估值结果给区间且敏感性表方向符合直觉（WACC 升 → 估值降）。
- 所有驱动假设能追溯到历史数据或明确依据。
