# 数据库与后端查询优化

仅在任务匹配本技能时应用。当前用户要求、系统规则与实际工具权限优先。此为GitHub上游技能的本机兼容适配版，默认中文输出。不要假定上游列出的工具、包、API密钥或Linux命令已可用；先检查环境，优先当前软件已有工具。不要自动调用收费服务、上传本地私密资料或运行上游安装命令。

定位慢查询、数据库索引、N+1查询及后端响应瓶颈。先记录数据规模、延迟分位数、吞吐量和资源占用，保留基准；读取执行计划，辨别全表扫描、排序、连接、锁等待和往返次数。先减少无效查询与字段，采用批量、合适分页及连接池，再根据实际过滤与排序建立索引。索引会增加写入和存储成本，不把扫描类型简单等同好坏。注意EXPLAIN ANALYZE实际执行SQL，写操作仅在授权测试环境执行。用相同数据和负载比较修改前后，验证结果与事务语义一致，提供收益、代价和回退方法。
