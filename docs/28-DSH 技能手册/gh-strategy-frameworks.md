# 战略分析与决策框架

## 适用场景

- 业务增长停滞，需要判断问题出在哪个环节。
- 面对多个方向要做取舍，需要结构化比较而非拍脑袋。
- 写战略规划、商业计划书中的战略章节。
- 不适用：市场规模测算（用 `gh-business-analysis`）；纯执行层排期（用 `gh-project-management`）。

## 前置条件

- 框架是思考工具，不是交付物。**先有问题，再选框架**；反过来填框架必然产出空话。
- 先把事实摆齐：收入构成、客户结构、成本结构、竞品动作、政策变化。

## 步骤

1. **先写清要回答的问题**，例如"该不该进入企业市场""要不要降价换量"。一句话能说清才算准备好。
2. **按问题选框架**：
   - 行业吸引力 → 波特五力（供应商、买方、替代品、新进入者、现有竞争）。
   - 自身优劣势 → SWOT + 价值链（找出真正创造差异的环节）。
   - 商业模式 → 商业模式画布（客户细分、价值主张、渠道、收入、成本、关键资源）。
   - 增长来源 → 安索夫矩阵（现有/新产品 × 现有/新市场）。
   - 竞争位置 → 成本领先 / 差异化 / 聚焦，三选一并说明为什么不选另两条。
3. **每个格子必须有事实支撑**，写不出事实的格子留空，不要用形容词填充（"我们的优势是技术领先"是空话；"我们的检索延迟 80ms，对手 400ms"才是事实）。
4. **做取舍**：战略的本质是放弃。明确写出"我们不做 X，因为 Y"。
5. **落到可验证动作**：每个战略选择对应 1–2 个可量化里程碑与时间点。
6. **列出关键假设与失效信号**：什么情况出现说明这个战略判断错了。

## 常见坑

- SWOT 变成四格形容词墙，没有任何决策产出。
- 五个框架全做一遍，每份都浅，最后还得拍脑袋。一个清晰问题配一个主框架 + 一个交叉验证即可。
- 只在纸面上做差异化，实际成本结构不变——战略没有落到资源配置上等于没做。
- 混淆战略与目标："三年做到行业第一"是目标不是战略，战略回答"靠什么赢"。
- 忽略组织能力：战略要求的能力当前团队根本不具备，且短期无法补齐。

## 验证

- 每个结论能追溯到具体事实或数据。
- 明确写出放弃项与理由。
- 有可量化的里程碑和失效信号。

## 参考

- 与 `gh-business-analysis`（事实与规模）、`gh-financial-modeling`（资源投入测算）、`gh-project-management`（执行落地）配合。
