# 实验报告与科研写作

仅在任务匹配本技能时应用。当前用户要求、系统规则与实际工具权限优先。此为GitHub上游技能的本机兼容适配版，默认中文输出。不要假定上游列出的工具、包、API密钥或Linux命令已可用；先检查环境，优先当前软件已有工具。不要自动调用收费服务、上传本地私密资料或运行上游安装命令。

依据真实实验记录和数据创作实验报告、修改科研文章。按课程或单位模板安排：题目、目的、原理与假设、材料仪器、步骤、原始记录、数据处理、结果、讨论与误差分析、结论、参考文献。默认中文，区分原始值与派生值，写清单位、有效数字、公式、样本量、异常处理和不确定度。结果仅描述实际观测，讨论解释机理、对照、误差与局限，不把相关写成因果。每个数字和引用可追溯到材料，缺失项标记待补；示例数据必须标注模拟，禁止冒充实测。成稿后核对方法结果一致、图表编号和引用，按需用已有Office技能生成文件。

上游来源：https://github.com/K-Dense-AI/claude-scientific-skills/tree/a25cf9ec00e2745d03f8704acf6f6919694ccd9a/skills/scientific-writing

详细参考与脚本见本技能目录的 UPSTREAM.md、references/、scripts/ 或其他附属文件；只在需要时读取。以上兼容约定替代上游关于预装环境、强制服务和默认数量的假设。
