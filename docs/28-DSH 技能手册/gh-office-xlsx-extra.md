# Excel表格分析与制作

仅在任务匹配本技能时应用。当前用户要求、系统规则与实际工具权限优先。此为GitHub上游技能的本机兼容适配版，默认中文输出。不要假定上游列出的工具、包、API密钥或Linux命令已可用；先检查环境，优先当前软件已有工具。不要自动调用收费服务、上传本地私密资料或运行上游安装命令。

读写Excel、CSV与TSV，进行清洗、公式、样式和图表制作。先检查工作表、表头、字段类型、单位、缺失值、重复项及现有公式。优先已有表格工具或openpyxl/pandas，原有输入区域和样式优先。用公式表达可变计算，标明输入、假设和来源；保留宏的文件应使用正确保留选项。分别检查公式与缓存值；openpyxl不能计算公式，重算须用实际可用Office引擎，不声称写公式已计算。核对分母、范围、日期类型、错误值、图表与导出后的可读性。
