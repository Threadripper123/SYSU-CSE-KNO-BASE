# 营销与增长分析

## 适用场景

- 分析转化漏斗：用户在哪一步流失、为什么。
- 评估渠道质量与投放 ROI。
- 做用户分群与留存分析，找出高价值人群。
- 不适用：市场规模与竞争分析（用 `gh-business-analysis`）；财务回报测算（用 `gh-financial-modeling`）。

## 前置条件

- 需要事件级数据：用户 id、事件名、时间戳、渠道来源、属性。**没有埋点就没有分析**，先补埋点。
- 明确北极星指标：是 GMV、活跃数、留存率还是付费率？指标不同，优化方向完全不同。
- 明确分析窗口（观察期与回看期），否则留存口径不可比。

## 步骤

1. **先定漏斗**：把关键路径拆成 3–6 步（曝光 → 点击 → 注册 → 激活 → 付费 → 复购），每步定义明确的完成事件。
2. **算转化率并定位断点**：逐步转化率、整体转化率、每步流失人数与流失率。找出流失最大的那一步作为优化重点，而不是平均用力。
3. **分群拆解**：按渠道、设备、地区、新老用户、注册时段拆开看漏斗。**整体转化率不变但各群都在变化（辛普森悖论）** 是常见陷阱。
4. **留存分析**：用同期群（cohort）按注册周/月分组，看第 1/7/30 天留存曲线；比较不同渠道的留存曲线形状，而不只看首日。
5. **渠道归因**：
   - 末次点击：简单但高估转化型渠道。
   - 首次点击：高估引流渠道。
   - 线性/时间衰减：更公平但需要完整触点数据。
   - 多方法对比，差异大的结论要谨慎。
6. **ROI 计算**：`ROI = (收入 − 成本) / 成本`，成本含投放 + 人力 + 工具；收入要扣退款与坏账。同时看回收周期（CAC 回本需要几个月）。
7. **A/B 实验**：随机分流、样本量预估、单一变量、显著性检验。实验期间不要中途偷看数据就下结论（peeking problem）。

## 常见坑

- 只看整体转化率不做分群，被辛普森悖论误导（每个渠道都变好但整体变差）。
- 留存用"次日留存"单一指标，忽略长期留存曲线是否趋平。
- 归因模型只用一个，把功劳全给末次渠道。
- ROI 不含人力与工具成本，虚高。
- A/B 实验样本不足就宣布显著，或实验组对照组不随机（如按时间分流）。
- 埋点缺失或重复上报，事件数虚高。
- 用累计用户数做分母算留存，口径完全错误（应用同期群固定初始人数）。

## 验证

- 漏斗每步都有明确的事件定义与口径说明。
- 分群结果与整体结果对比，解释差异。
- 留存用固定同期群基数计算。
- 实验有样本量计算与显著性检验结果。
