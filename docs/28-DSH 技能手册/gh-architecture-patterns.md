# 系统架构与模块设计

仅在任务匹配本技能时应用。当前用户要求、系统规则与实际工具权限优先。此为GitHub上游技能的本机兼容适配版，默认中文输出。不要假定上游列出的工具、包、API密钥或Linux命令已可用；先检查环境，优先当前软件已有工具。不要自动调用收费服务、上传本地私密资料或运行上游安装命令。

用于系统设计、后端模块拆分、单体重构和依赖循环。先明确业务边界、用户规模、读写比例、延迟与可靠性目标、部署条件和预算。画出组件、数据流、存储、信任边界及故障点。评估整洁架构、六边形端口适配器和领域边界；核心业务不依赖框架与数据库，外部依赖由接口隔离。按实际复杂度选择模块化单体或服务拆分，明确事务一致性、幂等、超时、重试、限流、观测和恢复。对至少两种合理方案写出取舍及适用阈值，交付接口契约、数据模型、迁移步骤和验证方案。
