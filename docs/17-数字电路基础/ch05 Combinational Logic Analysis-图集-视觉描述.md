1. **Analog-to-digital converter (模拟到数字转换器)**：将模拟温度信号转换为8位二进制代码。2. **Binary-to-BCD converter (二进制到BCD转换器)**：将8位二进制代码转换为8位BCD码，用于表示测量温度。3. **Temperature-control logic (温度控制逻辑)**：接收8位BCD码作为输入，并根据指定的温度输出控制信号。图上出现的文字标签和数值包括：
- **T_analog**：模拟温度输入。- **8-bit binary code**：模拟温度转换后的8位二进制代码。- **8-bit BCD for measured temperature**：BCD码表示测量温度。- **8-bit BCD for specified temperature**：BCD码表示指定温度。- **T**：输出温度控制信号。这张图说明了温度控制系统如何将模拟温度信号转换为数字信号，并通过BCD码表示温度，以便进行温度控制。

## ch05 Combinational Logic Analysis-图集 第 54 页
这是一张电路图，显示了一个逻辑电路的结构。图中包含多个与非门（AND-OR-INV）和一个输出端T。输入端TM1到TM8表示测量温度的BCD码，而输入端TS1到TS8表示指定温度的BCD码。输出端T表示最终的温度值。
