# BS-02 物理 2023–2026：LHC Run 3、muon g-2、DESI 暗能量、JWST、引力波、量子计算

一句话结论：这三年物理的主线是“标准模型更稳、暗能量更疑、引力波更响、量子纠错跨过阈值”——μ 子 g-2 的二十年反常基本收束，DESI 把“演化暗能量”推到 3–4σ 的嫌疑但未到发现，LIGO 三代目录把事件数推到 390 个，Google Willow 首次证明表面码可以“越大越好”。

## 一、LHC Run 3 收官与 LS3：能量前沿进入“升级期”

CERN 的 LHC 页面明确写着：LHC 将运行到 **2026 年 7 月开始的 Long Shutdown 3（LS3）**，LS3 期间进行亮度升级，升级后的高亮度 LHC（HL-LHC）预计在 2030 年代中期重启，再运行至少十年。这意味着 2023–2026 这一窗口正好覆盖 Run 3 的后半段与收官：质子-质子对撞在 13.6 TeV 质心能量下积累数据，重离子与特殊运行穿插进行。

Run 3 的物理产出有一个特点：**没有单一的“发现”，但把标准模型的检验密度推高了**。Higgs 耦合的精度、稀有 B 衰变、超对称与暗物质候选者的排除边界，都在这三年里被系统性推进。截至 2026-11，大量分析仍在使用 Run 3 完整数据集，结论会滞后一到两年，这是对撞机物理的常态，不应把“没有大新闻”误读为“没有进展”。

| 阶段 | 时间 | 状态 |
|---|---|---|
| Run 3 | 2022–2026-07 | 已完成/收官 |
| LS3 | 2026-07 起 | 进行中 |
| HL-LHC | 2030 年代中期起 | 建设中/规划 |

## 二、μ 子 g-2：二十年的反常如何收束

2025 年 6 月，Fermilab 的 Muon g-2 合作组发布最终测量：把 2021、2023 与 2025 年三次结果合并，得到

`a_mu = 1,165,920,705(148) × 10^-12`

总精度 **127 ppb**，比布鲁克黑文（BNL）E821 的旧结果提升四倍以上；若再把 BNL 数据合并，世界平均精度约 124 ppb（后者见合作组会议报告，属于会议材料而非期刊终稿）。

更关键的变化在理论侧。2025 年 5 月的 WP25 更新（arXiv:2505.21476）指出：QED 与电弱贡献已进一步固化，强子贡献仍是误差主项；强子光-光散射的不确定度几乎减半；而**leading-order HVP 的取值发生了根本变化**——CMD-3 对 `e+e- → π+π-` 截面的新测量，使数据驱动的各套评估彼此矛盾到“无法有意义地合并”，作者转而采用精度约 0.9% 的格点 QCD 平均值。换句话说，实验精度已经好到“理论怎么算”本身成为争议焦点。

这带来一个重要的叙事修正：过去媒体常说“μ 子 g-2 有 4.2σ 新物理偏差”，那是 2021 年基于旧 HVP 的说法；到 2025–2026 年，随着实验终值与理论更新，**偏差显著收窄，反常更像是对强子物理理解的考验，而不是新物理的确证**。任何仍引用“4.2σ”的文章都停留在旧结论。

## 三、DESI：演化暗能量的 3–4σ 嫌疑

DESI 的 DR2 结果基于三年观测、超过 **1400 万个星系与类星体**的 BAO 测量。核心数字：

- 平坦 `ΛCDM` 下，BAO 偏好的参数与 CMB 有约 **2.3σ** 的张力；
- 允许 `w0waCDM` 时，DESI BAO + CMB 对“演化暗能量”的偏好为 **3.1σ**；
- 再加入超新星样本，偏好度在 **2.8–4.2σ** 之间，取决于用哪一套 SNe；
- DESI + CMB 给出中微子质量总和 95% 上限 **Σmν < 0.064 eV**。

这不是“发现暗能量在演化”。3–4σ 在粒子物理里只是“值得继续追”，离 5σ 的发现门槛还有距离；而且偏好度对超新星样本的选择敏感，说明系统误差尚未完全受控。2026-07-30，DESI 又发布了 DR2 的 Lyman-α 关键论文，把高红移氢云吸收作为独立探针，官方说法是“迄今该探针最精确的宇宙学约束”。这类独立探针的价值正在于：如果不同红移、不同方法都指向同一方向，`w0waCDM` 的可信度才会真正上升。

| 观测量 | 数值 | 限定 |
|---|---|---|
| DESI DR2 样本 | >1400 万星系/类星体 | 三年观测 |
| BAO vs CMB 张力 | 2.3σ | 平坦 ΛCDM |
| 演化暗能量偏好 | 3.1σ（BAO+CMB） | 不含 SNe |
| 含 SNe 的偏好 | 2.8–4.2σ | 依赖 SNe 样本 |
| Σmν 上限 | <0.064 eV | 95% 置信度 |

## 四、引力波：从“事件计数”到“种群物理”

O4 观测运行在 2025-11-18 结束。随后两份目录把引力波天文学推进到“统计时代”：

- **GWTC-4.0**（2026-03-05 新闻）：官方说法是“事件数比此前翻倍以上”；
- **GWTC-5.0**（2026-05-26）：新增 **161 个事件**（2024-04 至 2025-01），累计探测到的信号达到 **390 个**；亮点包括第二代黑洞的证据、迄今最精确的 sky localization、以及“最清晰的引力波信号”。

“第二代黑洞”指的是由前代黑洞并合产物再次并合形成的黑洞，这是检验星族演化与 pair-instability 质量间隙的关键。另一个 flagged 结果是 GW250114：这个 2025 年 1 月的并合事件信噪比极高，被用于检验 Hawking 面积定理与广义相对论的非线性 regime，2026-02 有专门的分析。

需要区分的是：**目录发布是官方事实，具体天体物理结论仍是论文层面的推断**。例如“第二代黑洞证据”依赖种群模型，不同先验会给出不同显著性；引用时应写明“在某种种群模型下”。

## 五、量子计算：Willow 跨过阈值，但离“有用”还远

2024-12-09 上线的《Nature》论文（Nature 638, 920–926, 2025）是这一周期最硬的量子硬件结果：Google 的 Willow 芯片用 **105 个物理比特**实现了距离 3、5、7 的表面码记忆，逻辑错误率随码距增加而指数下降，证明系统工作在**低于阈值**的区域。2026-04-28 该论文还发布了一次作者更正，说明数据与表述经过修订——这类更正不影响“跨阈值”这一定性结论，但提醒读者要引用最新版本。

“低于阈值”只回答了一个问题：**纠错码变大时，逻辑错误率会下降**。它不等于“逻辑比特已经比物理比特更可靠到可商用”，更不等于“量子优势”。2025 年被联合国定为“国际量子科学与技术年”，2026 年的竞争焦点已经从“比特数”转向“逻辑比特数、纠错开销、连接性”。对非专业读者，最实用的判别是：看到“量子霸权/量子优势”时，问它是哪个特定任务、对比的是哪一代经典算法、是否可扩展。

## 五点半、JWST 的交叉影响：不是“物理实验”，却改变了物理问题

JWST 是天文台，不是对撞机或引力波探测器，但它在 2023–2026 年对物理学的间接影响很实在。高红移星系样本显示，宇宙早期存在比模型预期更亮、更成熟的大质量星系，这迫使星系形成与反馈模型调整；同时，JWST 的红外测光为独立的距离阶梯与哈勃张力讨论提供了新数据点。需要克制的是：这些结果目前主要是“让模型更紧张”，而不是“推翻 ΛCDM”。把它写进物理综述时，应放在“宇宙学观测压力”一节，而不是当作标准模型被证伪的证据。

## 六、2026 年的两条边注：中微子与诺奖

2026-10-06，诺贝尔物理学奖授予 **Francis Halzen**，理由是他在中微子研究上的开创性工作（Fermilab 新闻标题为“groundbreaking neutrino research”；IceCube 是他长期主持的项目）。这不是“新发现”，而是对 IceCube 把高能中微子变成天文观测窗口的迟到承认。

同一时期，Fermilab 的短基线中微子项目 SBND 在 2026-10 发布首批结果，DUNE 在 2026-11 进入大规模地下建设阶段。中微子质量顺序、CP 破坏与惰性中微子搜索，是标准模型之外最明确的实验缺口之一。

## 七、对研究者和读者的实际影响

**对粒子物理研究者**：Run 3 收官意味着未来三到五年是“数据消化期”，而不是“新数据期”；年轻研究者应把精力放在分析方法的系统误差控制与 HL-LHC 的升级硬件上。

**对宇宙学研究者**：DESI 的 3–4σ 不是终点，而是“下一代实验必须解决系统误差”的动员令。Euclid、Rubin/LSST 与 DESI 的交叉验证，比单一实验的 σ 值更重要。

**对普通读者**：三个判别习惯能过滤大部分夸张标题——看显著性是否达到 5σ、看是预印本还是同行评议、看结论是否依赖某个模型先验。

## 八、常见坑与局限

1. **把 3σ 当发现**：DESI 的“演化暗能量”目前是嫌疑，不是定论；不同 SNe 样本给出 2.8–4.2σ 的区间本身就说明系统误差未收敛。
2. **引用过时的 g-2 偏差**：4.2σ 是旧 HVP 时代的数字；2025 年实验终值与 WP25 更新后，叙事已变。
3. **混淆“低于阈值”与“可用量子计算”**：Willow 证明的是纠错缩放，不是通用量子优势。
4. **把目录事件数当物理结论**：GWTC-5 的 390 个信号是事实，“第二代黑洞”是模型相关推断。
5. **忽略论文更正**：Willow 论文 2026-04 有作者更正，引用时应核对最新版本。
