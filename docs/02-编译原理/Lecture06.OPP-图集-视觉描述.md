## Lecture06.OPP-图集 第 2 页
这是一张电路图，描述了一个抽象的语法分析器模型，具体来说是一个移位-归约解析器。图中包含以下关键元素和连接：

1. **输入**：包含一个符号串 `n + n * n $`，表示输入的符号序列。2. **栈**：包含三个元素 `X`、`Y` 和 `$`，表示当前栈的状态。3. **移位-归约解析器**：这是核心组件，它从输入中读取符号，并根据当前栈的状态进行操作。4. **查找**：解析器通过查找栈顶元素和输入符号来决定下一步操作。5. **输出**：输出分为逻辑输出和物理输出，逻辑输出表示语法结构，物理输出表示具体的语法结构。这张图说明了移位-归约解析器如何通过栈和输入符号进行语法分析，从而生成语法结构。
