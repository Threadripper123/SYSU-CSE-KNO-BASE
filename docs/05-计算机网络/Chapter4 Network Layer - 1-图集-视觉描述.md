## Chapter4 Network Layer - 1-图集 第 32 页
这是一张电路图，描述了如何通过防火墙和网络地址转换（NAT）来建立直接通信的途径。图中包含以下关键元素：

1. **防火墙**：表示防火墙拒绝TCP和UDP的入站连接。2. **NAT**：表示网络地址转换，用于将内部网络地址转换为外部网络地址。3. **peer**：表示两个位于不同网络的实体，分别通过NAT进行通信。图中描述了两个位于不同网络的实体（peer）如何通过NAT和防火墙建立直接通信。具体步骤如下：
- 两个实体A和B分别位于192.168.1.10和10.0.0.10的网络中。- 通过NAT，实体A和B之间的通信被NAT所阻断。- 为了实现直接通信，需要在防火墙上创建一个洞（hole），允许UDP的入站连接通过。结论：通过防火墙和NAT的配置，可以实现两个位于不同网络的实体之间的直接通信。
