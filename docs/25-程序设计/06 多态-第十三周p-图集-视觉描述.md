   - 是否虚函数：-
   - 函数名：相同
   - 函数签名：不同

2. **隐藏/屏蔽（Overwrite）**：
   - 作用域：不同
   - 是否虚函数：否
   - 函数名：相同
   - 函数签名：不同

3. **覆盖（Override）**：
   - 作用域：不同
   - 是否虚函数：是
   - 函数名：相同
   - 函数签名：相同
