## string + inline + macro-图集 第 2 页
这是一张课程讲义的插图，图中包含以下内容：

1. **标题**：cstring 和 string
2. **内容**：
   - cstring 和 string 是表示字符串的不同方法，因此有不同，也有相似之处，如提供的函数的功能很相似，但使用方法不同。- 数据类型不同，头文件不同
     - cstring：以 null 字符结尾的字符数组，要调用对 c 串进行操作的函数，如 strlen, strcpy, strcmp 等函数要 include<string>
     - string 是一个类，类里包含数据和成员函数，要使用 string 这种数据类型，需要 include<string>
   - 建议：能使用 string，就不使用 cstring。结论：cstring 和 string 是两种不同的字符串表示方法，cstring 以字符数组形式存储字符串，而 string 是一个类，提供了更多的功能和特性。建议在使用时优先选择 string 类型。

## string + inline + macro-图集 第 4 页
这是一张课程讲义的插图，图的类型是文字描述。图上出现的文字标签、数值、坐标轴、表头或公式是关于inline内联函数与宏（macro）的相似之处和不同之处。相似之处包括每个调用都用定义进行替换，减少函数调用开销，提高程序效率，如果扩展较大或有较多扩展，可执行映像会变得相当大。不同之处包括宏是由预处理器扩展，内联函数由编译器扩展，宏展开做文本替换而不考虑代码的语义，但内联函数的扩展考虑语义，macro没有类型安全检查，与宏相比通常选择内联函数。

## string + inline + macro-图集 第 5 页
这是一张编程代码的截图，显示了一个C++程序的源代码。代码中使用了宏定义来计算平方值。关键元素和数值如下：

1. 宏定义：`#define SQUARE(x) ((x)*(x))`
2. 变量声明：`double a, b;`
3. 定义变量：`double c = 13.0;`
4. 宏调用：`a = SQUARE(5.0);`
5. 宏调用：`b = SQUARE(4.5 + 7.5);`
6. 输出变量：`cout << "a = " << a << ", b = " << b << endl;`
7. 输出变量：`cout << "c = " << c;`
8. 输出平方值：`cout << ", c square = " << SQUARE(c++) << endl;`
9. 输出变量：`cout << "Now c = " << c << endl;`
10. 函数返回：`return 0;`

结论：这段代码通过宏定义计算平方值，并输出结果。宏定义无法按值传递，因此需要使用`c++`来解决这个问题。
