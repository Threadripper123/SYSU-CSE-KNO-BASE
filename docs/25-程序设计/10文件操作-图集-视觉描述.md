2. **文件类型指针**：FILE
3. **打开文件**：使用 `fopen` 函数，传入文件名和文件方式（如 "w" 表示写入模式）。4. **关闭文件**：使用 `fclose` 函数，传入文件指针。图中还展示了一段C语言代码示例，用于打开和关闭文件：
```c
#include <stdio.h>

int main(){
    FILE *fptr = fopen("hello.txt", "w");
    if (fptr == NULL){
        printf("File could not be opened\n");
    } else {
        fprintf(fptr, "HelloWorld!");
        fclose(fptr);
    }
}
```

图的结论是：通过 `fopen` 函数可以打开文件，通过 `fclose` 函数可以关闭文件。
