## ch7.1-7.3 点估计-评选标准-图集-矢量 第 5 页
这张图是一张课程讲义中的插图，展示了一个概率论中的似然函数和最大似然估计的推导过程。图中包含以下关键元素：

1. **似然函数**：
   - \( L(p) = \prod_{i=1}^{n} p^{x_i} (1-p)^{1-x_i} \)
   - \( L(p) = p^{\sum_{i=1}^{n} x_i} (1-p)^{n-\sum_{i=1}^{n} x_i} \)

2. **对数似然函数**：
   - \( \ln L(p) = \left( \sum_{i=1}^{n} x_i \right) \ln p + \left( n - \sum_{i=1}^{n} x_i \right) \ln (1-p) \)

3. **似然函数的导数**：
   - \( \frac{d}{dp} \ln L(p) = 0 \rightarrow \hat{p} = \frac{1}{n} \sum_{i=1}^{n} x_i = \bar{x} \)

4. **结论**：
   - 通过求导并令导数为0，得到似然函数的极大似然估计值 \(\hat{p} = \bar{x}\)，即样本平均值。这张图说明了如何通过似然函数和对数似然函数的导数来求得最大
