# BMC 维度路线与 Boss 攻略

## 1. 维度推进总路线

BMC4/BMC5 的设计是**用维度相互卡进度**，自然顺序：

```
主世界 Overworld
   ↓ 黑曜石传送门
下界 Nether（生物群系重做、要塞更大）
   ↓ 萤石传送门 + 水激活
以太 Aether（浮空岛）
   ↓ 2×2 水坑 + 一圈花 + 丢入钻石
暮色森林 Twilight Forest（魔法森林，Boss 强制顺序）
   ↓
Blue Skies（Everbright / Everdawn 双维度）
   ↓ 要塞传送门
末地 End（重做的末影龙战，需召唤仪式）
```

各维度进入方式细节：

| 维度 | 进入方法 | 说明 |
|---|---|---|
| 下界 | 标准黑曜石传送门 | 生物群系与要塞重做 |
| 以太 Aether | 用萤石搭门，再用水激活 | 浮空岛、青铜/白银/黄金地牢 |
| 暮色森林 | 挖 2×2 坑灌水，四周摆花，丢入**钻石** | Boss 顺序不可跳 |
| Blue Skies | 模组内传送门 | Everbright 与 Everdawn 两个相连维度，各自有 Boss 与材料 |
| 末地 | 常规要塞传送门 | 末影龙战改为需要召唤仪式 |

## 2. 暮色森林 Boss 链（严格顺序，不可跳）

1. **Naga**（娜迦）
2. **Lich**（巫妖）
3. **Minoshroom**（米诺菇）
4. **Hydra**（九头蛇）
5. **Knight Phantom**（幻影骑士）
6. **Ur-Ghast**（恶魂之主）
7. **Alpha Yeti**（雪怪首领）
8. **Snow Queen**（冰雪女王）

这条链是硬性的：前一个没打，后一个的地牢/进度不会开放。跨版本基本一致（BMC2/3 也保留了暮色森林，但整体 Boss 池不同）。

## 3. 以太 Aether 的三个 Boss

以太按地牢层级锁 Boss：

| Boss | 解锁地牢 |
|---|---|
| **Slider** | 青铜地牢 |
| **Valkyrie Queen** | 白银地牢 |
| **Sun Spirit** | 黄金地牢 |

BMC4 额外用 **Deep Aether**、**Aether Redux**、**Aether Villages** 扩了内容深度（村庄、材料、更多结构）。

## 4. BMC4 的 26 个 Boss 全名单

按来源分组（Minecraft-Guides 统计，标注"是否属于任务书"）：

- **以太（Aether）**：Slider、Sun Spirit、Valkyrie Queen —— 不属于任务书
- **Blue Skies**：
  - Everbright：Starlit Crusher（树形 Boss，**用斧头伤害更高**，需要长矛破防/眩晕创造输出窗口）、Summoner（闪电 + 能量攻击 + 石魔卫兵，击败后开启 Nature Dungeon）
  - Everdawn：Alchemist（药水与物理构造，攻击前有明显视觉预兆；击败后开启 Poison Dungeon）
- **Deeper and Darker（The Otherside 维度）**：Stalker
- **Cataclysm**：Ender Guardian、Ignis、Netherite Monstrosity 等
- **暮色森林**：Naga、Lich、Minoshroom、Hydra、Knight Phantom、Ur-Ghast、Alpha Yeti、Snow Queen
- **其他**：Awful Ghast、Nether Keeper、Eye of the Storm、Invoker、Karkinos、Shell Beast、Shelterer

> 注意：不同 BMC 版本的 Boss 池不同。BMC2 用 Bosses of Mass Destruction + Frostiful，BMC5 用 Raided + Friends & Foes，不能拿 BMC4 的名单对照别的版本。

## 5. 打 Boss 的通用准备（BMC 系列共识）

1. **先附魔再打**。BMC 的附魔与装备强度直接决定容错，跳过附魔是新手最常见的死法来源。
2. **在竞技场旁边放 Waystone**。死了之后能立刻回来，否则要重新穿越整个维度。
3. **带足方块与落地手段**。以太与 Blue Skies 都是空岛/浮空结构，摔死比被打死多。
4. **单人先试探一次**：BMC 的 Boss 多数有阶段性机制（护盾、召唤、地形攻击），第一次进去先观察而不是硬拼。

## 6. 非任务书内容的价值

以太与 Blue Skies 的 Boss **不在任务书里**，但它们是：

- 强力材料来源（Blue Skies 的双维度材料、以太的战利品）
- 部分 QoL 物品的前置（例如某些飞行/传送相关合成）

所以"任务书没写"不等于"不用打"。任务书是引导线，不是内容边界。
