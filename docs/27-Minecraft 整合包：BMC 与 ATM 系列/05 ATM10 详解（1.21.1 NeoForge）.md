# ATM10 详解（1.21.1 / NeoForge）

## 1. 定位与关键变化

- CurseForge 项目 ID **925200**，作者 ATMTeam，下载 **23.0M**，最新 **8.5（2026-11-04）**
- Minecraft **1.21.1** + **NeoForge**（系列首次从 Forge 转向 NeoForge）
- 约 **500 个模组**，官方自述"2026 年最热门的整合包"
- 官方描述的关键句："最大的变化是我们现在使用 NeoForge，并且位于 1.21 版本。期待大量更新，因为模组还在陆续跟进。"以及"我们会继续增加大量新模组，同时追求更好的稳定性。"

**为什么转 NeoForge**：1.20.2 之后 Forge 分裂出 NeoForge，1.21 生态的主力开发集中在 NeoForge 侧。ATM10 跟随生态走，这也是它模组数量能到 500 的前提。

## 3. FAQ（官方 atm10/faq 原文要点）

### 游戏内

**Q：每隔几分钟出现的幽灵/彩蛋是什么？**
来自 **Corail Tombstone**。用 `/tbgui` 打开，在 effect 分类里关掉 ghost 开关。**该开关只有在 GUI 缩放设置为 4 时才显示**。
想永久关掉所有 Corail 节日事件，装 **BadCorailNoHolidays**；想保留部分，改 `atmInstall/configs/badcorailnoholidays-common.toml`。

**Q：怎么改 /home、/tpa 的冷却？**
编辑 `saves/<世界名>/serverconfig/ftb-essentials.snbt`。**必须停服/退出世界**才生效。顺带这里也能重新开启 `/back` 和 `/rtp`。

**Q：条件都满足了，任务却完成不了？**
任务界面右下角开启"编辑任务"（需要 OP），右键那个坏掉的任务 → **Complete Instantly**；或者点任务后右键奖励 → **Reset Progress**（这样还能拿奖励）。

**Q：怎么增加可认领/强制加载的区块？**
- 认领：`/ftbchunks admin extra_claim_chunks <player> <set/add> <amount>`
- 强加载：`/ftbchunks admin extra_force_load_chunks <player> <add/set> <amount>`

**Q：挖 Allthemodium / Vibranium / Unobtainium 什么都不掉？**
是 **Miner's Fervor** 附魔导致的。把它去掉再挖。

### 技术向

**Q：为什么某个模组还没进 ATM10？**
官方标准：不 buggy、不毁性能/进度、**已更新到 1.21**。如果模组支持 1.21 且支持 NeoForge，可以提建议。

**Q：屏幕像被持续伤害一样抖动、什么都做不了？**
这是玩家数据异常。**先备份世界**，然后用 **NBT Explorer** 改：
- 单人：`saves/<世界名>/level.dat` → Data → Player → `AbsorptionAmount` 设为 1，`Health` 设为 1，保存后进世界
- 多人：`world/playerdata/<玩家UUID>.dat`，同样改这两个值

**Q：推荐的 Java 参数？**
客户端 `?args21`、服务端 `?svargs21`（官方 Discord 的 #bot-spam 频道），通用参数见本文库《10 性能与服务端运维》。

**Q：启动就崩溃？**
大概率内存不足（`?allocate` 看分配方法）。不是内存问题就去 #atm10-techsupport 用 `?logs` 上传日志。

**Q：崩溃报 "Error code 1"？**
**Exit code 1 是 Minecraft 的通用错误**，等于"游戏没加载起来，不再尝试加载，请看启动器生成的错误日志"，本身不提供任何信息。要用 `?logs` 找到真正的报错。

## 5. Apothic Enchanting（ATM10 的附魔体系）

ATM10 用 **Apothic Enchanting** 取代了 ATM9 的 Apotheosis 附魔部分。目标是搭出**满级附魔台**：

### 满级书架清单

- 5× Echoing Sculkshelf
- 5× Soul-Touched Sculkshelf
- 1× Deepshelf of Arcane Treasures
- 1× Draconic Endshelf
- 1× Geode-Encased Bookcase of Stability

### 搭建顺序（关键门槛）

1. 做 16× Seashelf，15 个摆成附魔台阵型，第 16 个拿去附魔台**灌注**（3 EXP），再用灌注过的替换一个未灌注的，重复直到 16 个全是 Infused Seashelf（会多出 1 个）。**需要等级 45+**。
2. 破掉 13 个 Infused Seashelf，做 13× Crystalline Seashelf 摆回去。
3. 做 10× Dormant Deepshelf，灌注成 Deepshelf。**需要等级 60+**。
4. 用这 10 个做 5× Soul-Touched Sculkshelf + 5× Echoing Sculkshelf（要用 JEI 查配方，**需要击杀若干监守者**）。
5. 做 1× Geode-Encased Bookcase of Stability：灌注 Block of Amethyst 得到 Budding Amethyst，摆 10× Crystalline Seashelf + 5× 普通书架来灌注。**需要等级 65+**。
6. 做 1× Draconic Endshelf（需要 Infused Dragon's Breath）：摆 5× Echoing Sculkshelf + 2× Soul-Touched Sculkshelf + 5× Melonshelf + 5× 普通书架 + 1× Geode-Encased Bookcase of Stability 来灌注龙息。**需要等级 80+**。
7. 最后做 1× Deepshelf of Arcane Treasures，把上述 5 类书架摆好，满级附魔台完成。

**小技巧**：可以放 **Seashelf of Aquatic Filtration** 过滤掉不想要的附魔。

### 特定物品的灌注配方（书架组合）
