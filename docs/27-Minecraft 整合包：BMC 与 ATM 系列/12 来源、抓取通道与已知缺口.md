# 来源、抓取通道与已知缺口

> 本库所有事实都来自实际抓取，未抓到的内容不臆造；抓取失败的站点在下面逐条列明原因。

## 1. 采集时间

**2026-11-13 12:09–12:25（Asia/Shanghai）**。版本号、下载量、模组数均为该时点快照。

## 2. 实际使用的抓取通道

| 通道 | 用途 | 表现 |
|---|---|---|
| **read_page**（modsearch 云渲染） | CurseForge 项目页、g-portal 维基、allthemods.github.io、minecraft-guides.com | 主力通道，正文干净、支持 JS 渲染 |
| **web_fetch**（原始 HTTP） | GitHub API（`api.github.com/repos/AllTheMods/ATM-10/contents/README.md`）、CurseForge HTML | 拿结构化 JSON 最快 |
| **browser_open**（本机 Chrome + 持久化配置） | Fandom 维基（需代理 + 可见窗口） | 成功返回 200，但**该站字体映射异常，提取文本缺字母**（如 "Be er Minecraf Modpack"），仅能读结构 |
| **browser_search**（登录态站点内搜索） | Bilibili | 成功，30 条结果；CSDN 超时 |
| **web_search** | 早期定位官方页面 | 正常 |

## 3. 抓取失败/受限清单（重要）

| 目标 | 症状 | 判断 |
|---|---|---|
| `raw.githubusercontent.com/AllTheMods/ATM-10/main/README.md` | `TypeError: fetch failed` | 裸 fetch 无代理；已改走 GitHub Contents API 绕过，README 内容实际拿到 |
| `betterminecraftmodpack.fandom.com` | 裸 fetch 失败；headless 浏览器 403 | 加 Clash 代理 `http://127.0.0.1:7897` + 可见窗口后 200，但文本乱码（字体子集），信息量极低，**未采用其中内容** |
| `so.csdn.net` 站内搜索 | `net::ERR_TIMED_OUT` | 站内搜索页在浏览器里超时，未重试（避免触发风控） |
| `www.minecraft-guides.com/modpacks/all-the-mods-8/` 等 | `firecrawl returned 429 Too Many Requests` | 免费额度限流；改用 CurseForge 原页补齐 ATM6/7/8 数据 |
| `api.cfwidget.com` | JSON 在 100000 字符处被截断 / `unsupported content type` | 响应体过大被裁剪，**未采用** |
| `github.com/LunaPixelStudios/Better-MC-Forge-BMC4` | 404 | BMC 没有该公开仓库路径（或已改名），BMC 数据全部改用 CurseForge/Modrinth/g-portal |
| ATM 各包 GitHub **Releases** | 返回空数组 `[]` | ATM 团队不用 GitHub Releases 发版，版本信息只能从 CurseForge 取 |
| 部分 CurseForge 页面（ATM6/7/8 首次、BMC2） | read_page 首次解析出空正文 | 重试或改通道后恢复，非站点不可达 |

## 4. 已知信息缺口（不要假装有）

1. **ATM Star / Gregstar 的完整配方树未逐条收录**。它横跨 GregTech、Apotheosis、AE2、神秘农业等多条线，且 ATM 有自定义改动。查配方请用游戏内 **JEI/EMI**。
2. **BMC2/BMC3 的 Boss 逐只机制未收录**。只确认了它们的 Boss 来源模组（BOMD、Frostiful、Friends & Foes），没有 BOMD 每个 Boss 的技能细节。
3. **ATM10 的模组完整清单未收录**。约 500 个模组，官方没有单一可抓取的清单页；Minecraft-Guides 有分类统计（Utility & QoL 91、API/Library 92、Technology 91 等），但那是他们的统计口径。
4. **BMC 与 ATM 的模组数量在不同页面互相矛盾**（CurseForge 描述 vs Modrinth 描述 vs 第三方统计）。本库并列标注来源，没有强行统一成一个数字。
5. **中文一手资料几乎没有**。Bilibili 搜索结果里绝大多数是别的整合包（珍妮、奥特 100 天等），只有少量 ATM10 Sky 相关视频；CSDN 站内搜索超时。所以本库以官方英文源为准。
6. **The Aether 的「Slider 在青铜地牢」这类对应关系**来自 g-portal 的表述，属于社区/托管商整理，不是模组官方文档，细节可能有版本差异。
