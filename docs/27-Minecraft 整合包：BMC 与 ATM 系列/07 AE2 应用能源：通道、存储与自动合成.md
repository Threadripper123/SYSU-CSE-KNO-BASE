# AE2 应用能源（Applied Energistics 2）实战手册

> ATM 系列的核心存储与自动化模组。本库内容基于官方 All The Guides 的 AE2 章节（适用于任何含 AE2 的整合包）。

## 1. AE2 能做什么

- **物流**：通过 ME 系统在任意位置近乎瞬间地搬运物品，性能是所有模组里最好的之一。
- **存储**：存物品、流体，甚至 mana 与能量；可存数十亿物品，且能搜索。
- **自动合成**：用存储的物品自动合成，既可用 AE2 自己的分子装配室，也可驱动其它模组的机器；一次请求可以调度数百万物品、数十台机器。

## 2. 通道（Channels）——被误解最深的部分

### 基础规则

- **ME 控制器**每个面提供 **32 通道**。
- 没有控制器也能组网，但最多 **8 个设备**，这叫 **Ad-Hoc 网络**；供电可用 Energy Acceptor 或 Crystal Resonance Generator（后者直接接 AE2 线缆、免费产少量电）。
- **每个接入网络的设备消耗 1 通道**；线缆通道不够，设备就不工作。

### 线缆通道容量

| 线缆 | 通道数 | 是否显示占用 |
|---|---|---|
| Glass Cable | 8 | 否 |
| Covered Cable | 8 | 否 |
| Smart Cable | 8 | 是（需要 WAILA/TOP/Jade） |
| Dense Covered Cable | 32 | 否 |
| Dense Smart Cable | 32 | 是 |

- **整方块设备**（Interface、Pattern Provider 等）内部可透传 **8 通道**，相当于一小段线缆。
- **Covered 只是外观**，没有功能差异。
- **颜色**：17 种颜色（16 原版色 + Fluix 默认色）。**同色不互连，Fluix 与任意色互连**；要彻底阻断连接用 **Cable Anchor**。
- **隐藏线缆**用 **Facades**（用线缆锚包住任意方块）。
- **只供电不供通道**：用 **Quartz Fiber**。

### 无线/远距离搬通道

| 方案 | 通道 | 距离 | 备注 |
|---|---|---|---|
| ME Wireless Connector（ExtendedAE） | 32 | 短距离 | 可染色；**功耗随距离指数增长**；不能跨维度；需 Wireless Setup Kit 配对 |
| **Quantum Ring** | 32 | 无限 | **可跨维度**；3×3×1 多方块；用 Quantum Entangled Singularities 配对（炸一个末影珍珠 + 一个奇点得到两个） |

> 心智模型：通道像 USB 口。线缆是"一捆 USB 线"，控制器是"电脑"，每个设备要占一个口。口用完了，线再多也没用。

## 3. 存储：Types 与 Bytes

### 为什么有 Types 上限

NBT 物品（带独特数据的物品）无法堆叠，占用的内存远大于普通物品。**单个区块内存占用过高会让游戏崩溃，并且重进世界立刻再崩——等于存档被锁死。** Types 上限就是强制你别把 NBT 物品塞进 ME 驱动器。

**绝对不要相信"移除 Types 上限"的附属模组**：官方明确警告，这类模组大多没有任何保护，只是把崩溃延后。

### Bytes 计算

- 1 Byte = 8 个物品
- 每新增 1 个 Type，占用该元件总容量的 **1/128**
- 公式：`(总 Bytes − (已用 Types × 总 Bytes / 128)) × 8 = 可存物品数`

**1k 存储元件实例**（1024 Bytes、63 Types）：
- 只用 1 个 Type：`(1024 − 1×8) × 8 = 8,128` 个物品
- 用满 63 个 Type：`(1024 − 63×8) × 8 = 4,160` 个物品

### 元件速查

| 元件 | 类型 | Type 上限 | 容量档位 |
|---|---|---|---|
| ME Item Storage Cell | 物品 | 63 | 1K–256K |
| MEGA Item Storage Cell | 物品 | 63 | 1M–256M |
| **MEGA Bulk Cell** | 物品 | **1** | **无限** |
| ME/MEGA Fluid Storage Cell | 流体 | 18 | 1K–256K / 1M–256M |
| ME/MEGA Chemical Storage Cell | 化学品 | 15 | 同档 |
| ME/MEGA Mana Storage Cell | Mana | 1 | 同档 |
| ME/MEGA Source Storage Cell | Source | 1 | 同档 |
| ME FE Storage Cell | 能量 | 1 | 1K–256M |
| ME Infinite Water / Cobblestone Cell | 水/圆石 | 1 | 无限 |

**外部存储**：给箱子/桶接 **Storage Bus** 并**提高优先级**，AE2 就会把它当成存储元件，内容显示在终端里，并优先往里输入。

## 4. 自动合成

### 四种样板（Pattern）

| 类型 | 用途 | 关键点 |
|---|---|---|
| **Crafting Pattern** | 工作台配方 | 有 **Item Substitution / Fluid Substitution** 开关；有 NBT 物品或可复用工具时**关掉替换** |
| **Processing Pattern** | 任意机器流程 | 需自己填输入/输出；**没有替换机制**，所以可复用物品（如压印模板）**不要放进样板**，否则系统会为每次合成都造一个 |
| **Smithing Table Pattern** | 锻造台（钻石→下界合金） | 不需要真的连接锻造台 |
| **Stonecutting Pattern** | 切石机 | 不需要真的连接切石机 |

样板在 **Pattern Encoding Terminal** 里做，可以从 EMI 点 **+** 直接粘贴配方。

### Pattern Provider 与分子装配室

- **Pattern Provider** 是自动合成的核心：把样板要求的物品推入相邻机器。
- **Blocking Mode**：库存里已有物品时不再推下一批，适合 Powah 充能球这类机器。
- **Pattern Access Terminal** 可远程访问所有已连接的 Pattern Provider。
- **分子装配室（Molecular Assembler）**：负责所有非 Processing 样板。**最佳布局是 1 个 Pattern Provider 被 6 个装配室包围**。
- 装配室**不消耗通道**，但仍可透传 8 通道。
- 强烈建议插 **Acceleration Card** 提速。

### 合成 CPU

| 部件 | 作用 |
|---|---|
| Crafting Storage | 决定**单次合成能有多大**（子步骤数量），档位同存储元件，也用 Bytes |
| Co-Processor | 决定**并发推进速度**，比存储更重要 |
| Crafting Monitor | 显示当前合成 |
| Crafting Unit | 组成 CPU 多方块 |

- 每个 CPU 多方块**同时只处理 1 个请求**；要并行多个请求就多造几个 CPU。
- 结构**必须是长方体**，其它形状不工作。
- 经验比例：**Co-Processor 要远多于 Crafting Storage**。

## 5. 常见坑（ATM 环境特有）

1. **子网没有控制器时只有 8 通道**。做大型阵列（例如神秘农业的 Phyto 阵列）时，每一列要按 8 通道规划。
2. **同一颜色的线缆不会互连**，但**不同颜色的 Dense 线缆可以分担通道**，这是大型基地的常规做法。
3. **石英纤维只供电不给通道**，用在"我要给机器供电但不想让它占网络通道"的场合。
4. **NBT 物品别进驱动器**，尤其是刷怪笼、附魔书、带自定义数据的工具。用 Bulk Cell 或外部存储 + Storage Bus。
5. **量子环跨维度**，是远程基地/挖掘维度接入主网络的标准方案。
