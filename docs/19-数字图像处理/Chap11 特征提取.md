弗里曼链码对旋转敏感，且依赖于初始点，可以采用归一化的方法：
用差分码（即用当前链码方向减去前一方向后，再取模数）代替链码，获得旋转不变；
例子(考虑4向链码)：
原链码：1       0       1       0       3      3       2       2
差分码：1-2   0-1    1-0   0-1   3-0   3-3   2-3   2-2
-1     -1      1      -1      3       0      -1     0
对4取模：3      3      1       3       3       0      3      0
形状数：将码按一个方向循环，使其构成的自然数最小
0      3      0       3       3       1      3      3
此操作克服起始点敏感问题。
注意：形状数不是一个数，是一个形成最小值的序列。
