# SYSU-CSE-KNO-BASE

中山大学计算机学院课程知识库（文本版）：把本地 DSH 知识库中的课件、教材、讲义转成 Markdown 集中发布，
便于直接浏览、全文检索与二次加工。

- 主题库 **28 个**　｜　文档 **1,579 篇**　｜　正文 **22.3 M 字符**
- 每篇含：标题、所属主题库、原始文件名、抽取正文（图片与图表已转成文字描述）
- 原始 PDF/PPT 不入库（共 23.5 GB，超过 GitHub 单文件 100 MB 限制）

## 怎么用

```bash
git clone https://github.com/Threadripper123/SYSU-CSE-KNO-BASE.git
cd SYSU-CSE-KNO-BASE
grep -rn "B+ 树" docs/        # 全库检索术语
grep -rln "一致性哈希" docs/   # 只看命中的文件
```

index.json 提供机器可读清单（主题、标题、路径、源文件名、字符数），可用于二次索引或自建检索工具。

## 说明

- 正文由 PDF/PPT 自动抽取；幻灯片中的图片与图表已由视觉模型转成文字描述，因此会出现「图：…」「视觉描述」一类段落。
- 每篇开头标注原始文件名与所属主题库，便于回溯到本地课件。
- 少数 PPTX 抽取异常（返回原始 OOXML）的文档已清洗为纯文本后收录，个别版式信息会丢失。
- 抽取质量受原文件排版影响，公式、复杂表格、手写内容可能有缺损，以原始课件为准。
- 课程资料著作权归中山大学及各位任课教师所有，本仓库仅用于个人学习与检索，请勿用于商业分发。
